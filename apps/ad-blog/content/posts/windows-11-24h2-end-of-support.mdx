Windows 11 version 24H2 Home and Pro no longer get security updates. Their last one came on October 13, 2026, and Microsoft's November 10, 2026 security update, KB5132061, went to versions 25H2 and 26H2 and to the Enterprise and Education editions of 24H2, but not to 24H2 Home or Pro. A PC that stays on 24H2 keeps working, but every security hole Microsoft fixes from now on stays open on it.

The way out is free and takes one restart. Check your version in **Settings > System > About**. If it says Home or Pro and version 24H2, open **Settings > Windows Update**, select **Check for updates**, and install **Windows 11, version 26H2** when it's offered. Version 26H2 gets security updates until October 10, 2028.

We checked Microsoft's release information, release health status pages, update articles and Windows 11 download page on November 11, 2026. The steps below come from that documentation; we don't run Windows in our test setup.

## Which Windows 11 versions still get security updates?

Only versions 25H2, 26H2 and 26H1 still get monthly security updates on Home and Pro PCs, according to Microsoft's [Windows 11 release information](https://learn.microsoft.com/en-us/windows/release-health/windows11-release-information) page as of November 11, 2026. Microsoft groups Pro Education and Pro for Workstations with Home and Pro.

| If your PC runs... | Security updates until | What to do |
| --- | --- | --- |
| Windows 11 Home or Pro, version 24H2 | Ended October 13, 2026 | Update to 26H2 (below) |
| Windows 11 Home or Pro, version 23H2 | Already ended | Update to 26H2 |
| Windows 11 Enterprise or Education, version 24H2 (work or school PCs) | October 12, 2027 | Nothing yet; your IT team decides |
| Windows 11 Home or Pro, version 25H2 | October 12, 2027 | Nothing urgent; 26H2 adds a year |
| Windows 11 version 26H1 (some new 2026 PCs) | March 14, 2028 | Nothing |
| Windows 11 Home or Pro, version 26H2 | October 10, 2028 | Nothing |
| Windows 10 | Only through the paid or free ESU program | See our guide to [the Windows 10 security update extension](/posts/windows-10-esu-extended) |

Microsoft announced the 24H2 cutoff in its [Windows message center](https://learn.microsoft.com/en-us/windows/release-health/windows-message-center) on October 13, 2026, saying that month's update was "the last update available for these editions" and recommending 26H2 or 25H2. The November update confirmed it. The update article for [KB5132061](https://support.microsoft.com/en-us/help/5132061) lists who it applies to: "Windows 11 version 26H2, all editions," "Windows 11 version 25H2, all editions" and "Windows 11 Enterprise and Education, version 24H2."

## How to check if your PC is on Windows 11 24H2

Your Windows version and edition are listed on the **About** page in Settings. These steps follow Microsoft's guide to [finding information about your Windows device](https://support.microsoft.com/en-us/windows/experience/find-information-about-your-windows-device).

1. Right-click the **Start** button and choose **Settings**.
2. Select **System**, then **About**.
3. Under **Windows specifications**, look at **Edition** and **Version**.

If **Edition** says Home or Pro and **Version** says 24H2, your PC no longer gets security updates. If it says 25H2 or 26H2, you're covered for now. A work or school PC usually shows Enterprise or Education, and its updates are managed by the organization.

## How to update from Windows 11 24H2 to 26H2

You update from 24H2 to 26H2 in **Settings > Windows Update**, and the update finishes with a single restart. Microsoft's [24H2 status page](https://learn.microsoft.com/en-us/windows/release-health/status-windows-11-24h2) says the 26H2 rollout "has reached full availability for devices running Windows 11, versions 25H2 and 24H2."

1. Save your open work, since the PC will restart.
2. Open **Settings > Windows Update** and select **Check for updates**. Install anything that's offered first and restart if asked.
3. When **Windows 11, version 26H2 is available** appears on the page, select **Download & install**.
4. Restart when Windows asks. Afterward, the **About** page shows **Version 26H2**.

The same Windows Update page has a switch called **Get the latest updates as soon as they're available**. Microsoft's [26H2 status page](https://learn.microsoft.com/en-us/windows/release-health/status-windows-11-26h2) suggests turning it on if you want updates installed as soon as they're available.

The update is small because most of 26H2 is already on your PC. Microsoft's article for the update, [KB5121794](https://support.microsoft.com/en-us/servicing/os/windows-11/2026/09/kb5121794-feature-update-to-windows-11-version-26h2), says versions 24H2, 25H2 and 26H2 "share a common core operating system with an identical set of system files." The 26H2 features arrive switched off inside the monthly updates, and the 26H2 update is a small "enablement package," which Microsoft calls a "master switch," that turns them on. The only requirement is the September 22, 2026 update or any later one, which a 24H2 PC that installed the October 13 update already has.

## What if Windows Update doesn't offer 26H2?

If Windows Update says the update is on its way but not ready for your PC, wait. Microsoft's [safeguard holds page](https://learn.microsoft.com/en-us/windows/deployment/update/safeguard-holds) says this message means Microsoft found a compatibility problem on PCs like yours, and it recommends that you "don't attempt to manually update until issues have been resolved and holds released." As of November 11, 2026, every known issue on the 26H2 status page is marked resolved.

If Windows Update offers nothing and shows no hold message, Microsoft's [Windows 11 download page](https://www.microsoft.com/en-us/software-download/windows11) lists 26H2 as the current release of the free **Windows 11 Installation Assistant**. Microsoft says you need a Windows license, 9 GB of free disk space and an administrator account, and that the assistant works only on PCs with Intel or AMD (x64) processors. On an Arm-based PC, the same page says to wait until Windows Update tells you the upgrade is ready.

## What happens if you stay on Windows 11 24H2?

A PC that stays on 24H2 Home or Pro keeps working but stops getting fixes. Microsoft's [lifecycle FAQ](https://learn.microsoft.com/en-us/lifecycle/faq/windows) says an unsupported version "may still work with programs and hardware," but it no longer gets "software updates, or security fixes." The first missed update was November 10, 2026. The next ones are due on the second Tuesday of each month, starting December 8, 2026.

![Bar chart of security updates left for a Windows 11 Home or Pro PC on version 24H2, counted from November 11, 2026: staying on 24H2 gives none, with the first missed update on November 10, 2026; updating to 25H2 gives about 11 months, until October 12, 2027; updating to 26H2 gives about 23 months, until October 10, 2028](./images/windows-11-24h2-end-of-support/security-updates-left-by-version.webp)

Staying on 24H2 also means missing bug fixes. Microsoft's 24H2 status page says that after the September 8, 2026 update, some USB Audio Class 1.0 devices might fail to start, with "This device cannot start (Code 10)" in Device Manager, no sound or volume controls that don't respond. Microsoft marks the issue "Resolved KB5132061," the November update that 24H2 Home and Pro PCs aren't offered. Moving to 26H2 makes the PC eligible for that update again.

New features skip 24H2 too. Windows 11's [new customizable right-click menu](/posts/customize-right-click-menu-windows-11) began rolling out to 25H2 and 26H2 in an October 28, 2026 update, and 24H2 Home and Pro won't get it.

Don't leave the move for too long. In the message center, Microsoft says the certificates Windows Update uses for secure connections expire in 2027, and that 24H2 PCs need the September 2025 security update or later before June 19, 2027. A PC without the newer certificates "will lose access to Windows Update" after that date. A 24H2 PC that installed the October 2026 update already meets that requirement, but a PC that stopped installing updates long ago may lose its easy path to 26H2.

## Should you choose 26H2 or 25H2?

Choose 26H2. It's the version Windows Update offers 24H2 PCs, it takes the same single restart, and it gets security updates until October 10, 2028, a year longer than 25H2's October 12, 2027 end date. Microsoft recommends either version in its message center, but we didn't find a Microsoft document that explains how to pick 25H2 on a 24H2 PC that Windows Update is offering 26H2.

The usual reason to put off a Windows feature update, fear of a big reinstall that breaks something, applies less here. The 26H2 files are already on any up-to-date 24H2 PC, so the update only switches on features that are already installed. The 26H2 status page listed no open known issues on November 11, 2026, and the two problems it listed in late October, a Remote Desktop error on business-managed PCs and the USB audio failure above, are both marked resolved.

If you see a safeguard hold, don't force the update. A hold means Microsoft has a specific reason to think 26H2 will cause trouble on your hardware or with an app you have. Check Windows Update again after each monthly update.

## Windows 11 dates to remember

- **December 8, 2026.** The second monthly security update that 24H2 Home and Pro won't get. Microsoft says there will be no optional preview update in late December 2026.
- **June 19, 2027.** Windows Update certificate deadline: 24H2 PCs need the September 2025 update or later by then.
- **October 12, 2027.** Version 25H2 Home and Pro, and 24H2 Enterprise and Education, reach end of updates.
- **October 10, 2028.** End of updates for 26H2 Home and Pro.

The 24H2 cutoff was one of several Microsoft deadlines this fall that are worth checking on a family PC. If anyone in your house still uses Windows 10, check that it's enrolled in [Extended Security Updates through October 2027](/posts/windows-10-esu-extended). If you pay for Microsoft 365 Family, note [the move from 1 TB per person to 2 TB shared](/posts/microsoft-365-family-storage-2tb). If that PC has a one-time-purchase Office, check its version too: [Office 2021 lost support on the same day as 24H2](/posts/office-2021-end-of-support). And if anyone reads work email in Mail on a Mac, Microsoft's Exchange change can stop it syncing: see [why Apple Mail Exchange accounts stop syncing](/posts/apple-mail-exchange-not-syncing).
