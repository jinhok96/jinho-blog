## 쓰지 않은 것

- 다른 브라우저(Chrome·Firefox·Edge·Safari·Zen)가 Arc에서 직접 가져오기를 지원하는지: 각 브라우저 공식 문서에서 Arc 항목을 확인하지 못함 (Firefox 지원 문서는 컨테이너에서 본문을 못 읽음) → 쓰지 않고, Arc 도움말이 안내하는 경로(Dia 또는 링크 목록)만 씀. Chrome 확장 "Arc Import"(제3자, 0.1.0)도 확인하지 않아 뺌
- Arc 비밀번호를 CSV 등으로 내보내는 방법: Arc 도움말에 없음 → "Arc's help pages don't describe exporting passwords for another browser"로만
- Arc Max가 무료였는지: Arc Max 도움말 문서(19335160678679)가 현재 목록에 없어 확인 못 함
- Arc 사용자 수, 종료 결정 배경 보도(인터뷰·Atlassian 인수 금액 등)
- Zen·Vivaldi 등 대체 브라우저 추천 (The Verge 등 보도의 의견) → backlog 상시 글 후보로
- 앱 화면 직접 실행: Arc·Dia는 macOS·Windows 전용이라 Linux 컨테이너에서 설치·실행 못 함 → How we checked에 밝힘
