PUB
– Microsoft Publisher File

PUB is the native file format of Microsoft Publisher, a desktop publishing application. These files can contain layouts for various publications such as newsletters, brochures, flyers, and marketing materials. The format stores text, graphics, images, and layout information in a proprietary binary file. Publisher files are primarily compatible with Microsoft Publisher, which has been discontinued since 2016.

PDF is a document file format that contains text, images, data etc. This document type is Operating System independent. It is an open standard that compresses a document and vector graphics. It can be viewed in web browsers if the PDF plug-in is installed on the browser.
