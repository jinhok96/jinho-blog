Find information about your Windows device
 Applies ToWindows 11 Windows 10 
Note
- Support for Windows 10 has ended on October 14, 2025
- After October 14, 2025, Microsoft will no longer provide free software updates from Windows Update, technical assistance, or security fixes for Windows 10. Your PC will still work, but we recommend moving to Windows 11.
- Learn more
This article shows how to find basic information about your Windows device, including your device name and model, the version of Windows you’re running, your device specifications, and available storage.
Expand each section to learn more:
What's my device name and model?
To find your device name and model, you can use one of the following methods:
- Right-click Start and choose Windows Settings
, select System and pick About.
- Use the following link to quickly open settings:
Open About Settings
The device name appears on the page, with the model name displayed just below it.
Which version of Windows do I have?
To find your Windows version and edition, you can use one of the following methods:
- Right-click Start and choose Windows Settings
, select System and pick About.
- Use the following link to quickly open settings:
Open About Settings
Under Windows specifications, check which edition and version of Windows your device is running.
What are my device specifications?
To find your Windows version and edition, you can use one of the following methods:
- Right-click Start and choose Windows Settings
, select System and pick About.
- Use the following link:
Open About Settings
Under Device specifications, check details about your device including:
- Processor type.
- Amount of RAM installed.
- If the device is running a 32-bit or 64-bit version of Windows.
