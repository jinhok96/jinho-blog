Notable new features:
[Context menu]
Release channel: Experimental
Building on the work we’ve been doing to improve the context menu experience:
- We’ve added a new teaching tip you might see as a first-time experience to help you learn about the customization options.
- In theme with giving you more control, you can also now turn off the customize context menu entry in the new context menu settings.
- We’ve fixed a few small issues with the Send To option in the context menu not working as expected.
[File Explorer search]
Release channel: Experimental
- Search from This PC in File Explorer is now indexer-based, making it much faster and consistent with search from File Explorer Home.
