 Take action: NTLMv1 hardening changes might affect network connections on devices without Credential Guard
Beginning with the October 2026 security update, Windows 11, versions 26H2, 25H2, and 24H2, along with Windows Server 2025, enforce restrictions on generating NTLMv1-derived credentials for Single Sign-On by default. This planned security-hardening change is part of the boarder Microsoft effort to phase out NTLM and supported by Windows Credential Guard. This change applies only on devices with Credential Guard disabled, and might cause issues with Wi-Fi, Ethernet, and VPN connections that use MS-CHAPv2 authentication, resulting in possible failure to connect via Single Sign-On pathways.
Organizations should identify affected authentication configurations. Remove dependencies on MS-CHAPv2 and migrate Wi-Fi and VPN connections to certificate-based authentication. As a temporary option, it is possible to temporarily make changes to the Windows registry that set affected devices to allow and audit these connections. After removing dependencies, devices should be returned to enforcement.
Please note this is a planned change in Windows that supports evolving security needs, originally documented in August 2025. It is not a known issue with the October 2026 security update.
For complete rollout, auditing, and registry configuration guidance, as well as help to identify and remove remaining dependencies on NTLMv1-derived credentials, carefully review KB5066470. Learn about the disablement of NTLM at Advancing Windows security: Disabling NTLM by default - Windows IT Pro Blog, Retiring NTLM: Frequently asked questions - Windows IT Pro Blog.

 Manage Administrator protection within Windows 11 security baseline
If your organization uses Windows security baselines, Administrator protection becomes enabled by default with the October 2026 Windows security update. The security baselines for Windows 11 that enable Administrator protection by default apply to versions 26H2, 25H2, and 24H2. 
Review and test your security baseline configuration and adjust it as appropriate for your environment. Use Microsoft Intune or Group Policy to manage Administrator protection enablement as part of the security baseline. The following policies are part of the security baseline:  
- User Account Control: Configure type of Admin Approval Mode 
- User Account Control: Behavior of the elevation prompt for administrators running with Administrator protection 
Administrator protection is a platform security feature in Windows 11 designed to ensure users run with the least privilege needed, elevating to admin rights only when necessary and only with the user's explicit approval. 
The feature was introduced disabled-by-default in the August 2026 Windows non-security preview updates for Windows 11, versions 26H2, 25H2, and 24H2, through controlled feature rollout. With the September 2026 non-security preview update, the feature became generally available (off by default), along with enterprise management controls.
