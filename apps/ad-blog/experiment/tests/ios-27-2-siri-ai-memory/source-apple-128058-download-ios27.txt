How to download iOS 27

Check if your iPhone supports iOS 27, then download and install the update automatically or manually.

Before you update, back up your device to keep a copy of your important information.

Check compatibility

Turn on automatic updates

You can set up your iPhone to install updates automatically:

Open Settings.

Tap General.

Tap Software Update.

Tap Automatic Updates.

Choose Automatically Install or Automatically Download.

Automatically Install: Your iPhone downloads and installs updates overnight when it's charging and connected to Wi-Fi. You're notified before iPhone installs an update.

Automatically Download: Your iPhone downloads updates over Wi-Fi while it's charging and locked. You can then install them at your convenience. To see this option, first turn off Automatically Install.

Update iPhone manually

At any time, you can check for and install software updates:

Open Settings.

Tap General.

Tap Software Update.

If an update is available, tap Download and Install.

Follow the onscreen instructions.

Install the software update

If an update is already downloaded but not installed:

Open Settings.

Tap Update to iOS 27.

Tap Update Now or Update Tonight.

Follow the onscreen instructions.

View more details

The More Details section shows the version number and update details.
