Release notes for Office for Mac
Summarize this article for me

Office for Mac that comes with a Microsoft 365 subscription is updated regularly to provide new features, security updates, and non-security updates.

Updates are available from Microsoft AutoUpdate (MAU). To use Microsoft AutoUpdate, start an Office application, such as Word, and then choose Help > Check for Updates. If you're an admin and want to update the computers in your organization with your existing software deployment tools, you can download and deploy the update packages for each application.

 Note

These release notes also apply to Office LTSC 2021 and 2024 and Office 2021 and 2024, which are available as a one-time purchase from a retail store or through a volume licensing agreement. However, some features listed in the release notes are only available if you have a Microsoft 365 subscription.
We often roll out features over a period of time. This allows us to ensure that things are working smoothly before releasing the feature to a wider audience. If you don’t see something described below, you get it eventually. Learn more
We sometimes release updates containing general quality and performance improvements and no new features. If an app isn't listed, the update for that app includes only quality and performance improvements.
A minimum of macOS 14 (Sonoma) is required to receive updates to Microsoft 365 and Office apps. If you continue with an older version of macOS, your Office apps will still work, but you'll no longer receive any updates including security updates.
A minimum of macOS 12 (Monterey) is required to install versions 16.78 or later. Learn more
Office 2019 for Mac reached the end of support on October 10, 2023 and will no longer receive updates.
Copilot features are available to Microsoft 365 Copilot–licensed users.
Additional Copilot release notes can be found at Release Notes for Microsoft 365 Copilot.

Version 16.112 (Build 26081010)

Feature updates
Excel
Copilot in Excel Power BI grounding: Copilot in Excel can now ground analysis in governed Power BI data, bringing trusted business metrics directly into the Excel grid. Users can attach a Power BI report from the work content selector, then ask Copilot to analyze performance, identify trends, and build summaries or supporting calculations in Excel. Copilot works with the underlying report data while respecting existing row-level security, eliminating the need to export data, manually copy and reconcile figures, or switch between Power BI and Excel. This feature is currently rolling out to production for Windows, Mac, and web.
Copilot in Excel brand kit skill: The brand kit skill enables Copilot in Excel to format your workbook with your organization's brand kit from the Microsoft 365 Brand Center, automatically applying your approved colors, fonts, and logo to tables and charts so every report follows your company's branding guidelines. Just use the Brand-kit skill and ask Copilot to brand your sheet and get a polished, on-brand, presentation-ready report, without manual formatting.
Copilot in Excel: theme design skill: With the theme design skill users can now apply a coordinated design theme to their data, choosing a harmonized color palette, styling charts, and structuring the layout so your key insights stand out. Use the @theme-design skill and ask Copilot to design or polish your sheet and it delivers; ready formatting with clear visual hierarchy, turning raw data into a clean, readable report and saving you the manual styling work.
Copilot in Excel support articles: With significant investment in Copilot in Excel in the last few months, we refreshed all our Copilot in Excel support articles to reflect the new state of the feature. The support articles showcase new additions, like personalization, rules, skills, and formula suggestion management. They also highlight the many ways you can use Copilot in Excel in your daily work, such as visualizing your data or using data from your SharePoint or OneDrive.
Excel for Windows and Mac Copilot in Excel support for AutoSave-off workbooks: Copilot in Excel is now available in more cloud-saved workbooks, including files where AutoSave is turned off on Windows and Mac. Previously, Copilot required AutoSave to be on, which meant some users could not use Copilot in otherwise supported workbooks. When AutoSave is off and the workbook has unsaved changes, Excel reminds users to turn on AutoSave before Copilot starts making changes, helping protect unsaved work. Users can still choose to continue with Copilot without turning on AutoSave. This feature is currently rolling out to production for Windows and Mac users.
Outlook
Mail Theming: Links and At Mention colors in the reading pane now match the app's accent color.
Calendar: Outlook includes a new setting that lets you open new events in a separate window instead of a popover.
Calendar: The weather widget now uses the Liquid Glass visual design for a more modern and integrated appearance on supported versions of macOS.
Calendar: Outlook now includes a setting that automatically updates the default event creation time zone when your device's time zone changes.
Calendar: You can now choose to display My Day as an icon only mode in the menu bar from the My Day settings.
Copilot: Microsoft 365 Copilot Chat in Outlook is now available to customers in the GCC-H and DoD from Left Navigation Rail.
Copilot: Contextual Copilot actions are now available from standalone message and event-preview windows, making relevant assistance easier to access while you work.
Copilot: You can now upload images while working with the Researcher
