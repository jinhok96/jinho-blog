Note that the Microsoft Copilot app, which is a consumer experience, doesn't support Microsoft Entra authentication and users trying to sign in to the app using a Microsoft Entra account will be redirected to https://m365.cloud.microsoft/chat in their default browser. For users authenticating with a Microsoft Entra account, they should use the Microsoft Copilot app as the entry point.
