Firefox Release
October 13, 2026
Version 158.0, first offered to Release channel users on October 13, 2026

Firefox 157.0

Firefox 159.0
New
You can now fill in forms faster in Smart Window. When clicking into a form field or selecting Fill from sources, Smart Window will now suggest data to use based on your relevant open tabs and saved autofill data.
This feature is part of a progressive roll out.
What is a progressive roll out?
Certain new Firefox features are released gradually. This means some users will see the feature before everyone does. This approach helps to get early feedback to catch bugs and improve behavior quickly, meaning more Firefox users overall have a better experience.
Firefox now creates more accessible PDFs when saving a page as PDF, and when printing on Linux and macOS. This also fixes a variety of PDF rendering issues, such as missing math symbols.
Firefox now supports the JPEG XL image format, which generally has better compression than WebP, JPEG, PNG, and GIF.
New Tab now keeps a library of custom wallpapers under Your images, rather than only the most recent one.
Firefox's translations feature now supports the following languages:
Albanian
Belarusian
Filipino
Fixed
Fixed website icons (favicons) in address bar results blending into the highlight color when selecting a result with the keyboard on Ubuntu's default theme.
Fixed a crash that could occur while Firefox loaded website icons (favicons).
Fixed the first letter of each search engine's name being underlined in the Unified Search Button menu in the address bar on Windows and Linux, which could cause conflicting keyboard shortcuts.
Fixed menus such as List all tabs, Settings, and Unified Search being hard to read with a Windows High Contrast theme. Menu background and text colors now follow the Background and Text colors chosen for a custom contrast theme in Windows Settings.
Various security fixes.
Changed
Firefox no longer rounds scroll positions to whole screen pixels. Scrolling is now smoother and more precise, especially on high-resolution displays or when a page is zoomed.
Enterprise
For Firefox Enterprise updates and fixes, see the Firefox Enterprise Release Notes. For policy changes, see the Firefox admin docs changelog.
Developer
Developer Information
Fixed an issue where the Network Monitor could miss WebSocket messages if they arrived immediately after a connection was established.
Web Platform
Firefox now supports typed arithmetic in CSS calc(), allowing units to be multiplied and divided within math functions.
Added support for the navigate option for the Notification constructor and ServiceWorkerRegistration.showNotification(), which specifies a URL to navigate to when the notification is clicked.
The WebAuthn conditional UI is now shown on input elements with an autocomplete="webauthn" attribute. Previously, it was only shown when the attribute included another autofill field value, such as autocomplete="username webauthn". (Learn more)
Firefox now supports the cache value for PerformanceResourceTiming.deliveryType, allowing websites to identify resources served from the HTTP cache.
The WebGL extension EXT_polygon_offset_clamp is now available on compatible devices.
Unresolved
Web apps launched with the third-party PWAsForFirefox tool may fail to start in Firefox 158 and show the error "The installation seems to be incomplete." Updating PWAsForFirefox to version 2.20.1 or later fixes the issue. If the error persists, select "Reinstall runtime" and then "Patch profiles and runtime" in the PWAsForFirefox extension settings.
