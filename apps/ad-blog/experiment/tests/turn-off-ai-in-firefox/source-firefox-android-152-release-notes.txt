Firefox for Android Release Notes
Release Notes tell you what's new in Firefox for Android. As always, we welcome your feedback. You can also file a bug in Bugzilla or see the system requirements of this release.
152.0
Firefox for Android Release
June 16, 2026
Version 152.0, first offered to Release channel users on June 16, 2026
Enjoying Firefox? Leave a review. Got ideas or feedback? Join the conversation on Mozilla Connect. Need help? Our volunteer support community has you covered on Mozilla Support

Firefox for Android 153.0
New
World Cup widget: Follow live scores, match schedules and results in one place.
Page summaries: Get key points from long articles with a tap or shake. Now available to all users in English.
PDF sharing: Share the PDF file itself, or copy and share a link from the address bar.
Pinch zooming: Improved zooming performance on web pages, especially on lower-spec devices.
Fixed
Various security fixes.
