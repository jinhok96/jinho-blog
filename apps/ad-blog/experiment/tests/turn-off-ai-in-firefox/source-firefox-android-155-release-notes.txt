Firefox for Android Release Notes
Release Notes tell you what's new in Firefox for Android. As always, we welcome your feedback. You can also file a bug in Bugzilla or see the system requirements of this release.
155.0
Firefox for Android Release
September 1, 2026
Version 155.0, first offered to Release channel users on September 1, 2026
Enjoying Firefox? Leave a review. Got ideas or feedback? Join the conversation on Mozilla Connect. Need help? Our volunteer support community has you covered on Mozilla Support
Previous
Firefox for Android 154.0
Next
Firefox for Android 156.0
New
Toolbar shortcuts: Long-press a shortcut to edit its setting directly.
Tab groups: Ungroup and share them more easily.
Shake to summarize: Adjust shake sensitivity for easier access to page summaries.
Translations: Now supports Marathi and Urdu.
Fixed
Autofill prompts: Now automatically close when you move away from a field.
Text selection: Long-press now selects text inside buttons, so you can copy direct messages on X and comments on YouTube.
Background audio: Live audio streams such as internet radio now keep playing after the screen turns off.
Private extension tabs: Tabs opened by extensions while in private browsing now load privately, preventing site data from being left behind in regular browsing.
Various security fixes.
