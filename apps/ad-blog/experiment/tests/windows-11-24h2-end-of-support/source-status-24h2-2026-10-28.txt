Current status as of October 21, 2026 
As of October 13, 2026, Windows 11, version 24H2 Home and Pro editions have reached end of updates. Devices running these editions will no longer receive monthly security and non-security preview updates containing protections from the latest security threats. We recommend updating devices to Windows 11, version 26H2 or Windows 11, version 25H2 to continue receiving monthly security and quality updates.
The Windows 11, version 26H2 phased rollout has reached full availability for devices running Windows 11, versions 25H2 and 24H2. You can check for the update by going to Settings > Windows Update and selecting Check for Windows updates. If Windows 11, version 26H2 is available for your device, select Download & install. A single restart will complete the process. If you want updates to be installed as soon as they’re available, turn on Get the latest updates as soon as they’re available. For more details, watch this video.
Windows 11, version 24H2 Enterprise and Education editions remain supported until October 12, 2027.
