Current status as of October 21, 2026
Windows 11, version 26H2 has reached general availability. This new version contains all the recently announced features in Windows 11, versions 25H2 and 24H2 and will be delivered using servicing technology, providing a fast installation experience.
The Windows 11, version 26H2 phased rollout has reached full availability for devices running Windows 11, versions 25H2 and 24H2. You can check for the update by going to Settings > Windows Update and selecting Check for Windows updates. If Windows 11, version 26H2 is available for your device, select Download & install. A single restart will complete the process. If you want updates to be installed as soon as they’re available, turn on Get the latest updates as soon as they’re available.
