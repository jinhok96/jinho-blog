Anthropic은 Claude 개발자 플랫폼에 세 가지 주요 기능을 도입하여 AI 에이전트가 더 복잡한 작업을 효율적으로 수행할 수 있도록 지원합니다.

*   **도구 검색 도구 (Tool Search Tool)**: 수천 개의 도구에 대해 컨텍스트 창을 모두 사용하지 않고 Claude가 검색 도구를 사용하여 도구에 액세스할 수 있게 합니다. 이 기능은 도구 정의가 컨텍스트를 많이 차지하거나 도구 선택의 정확도가 문제가 될 때 유용합니다.
*   **프로그래밍 방식 도구 호출 (Programmatic Tool Calling)**: Claude가 코드 실행 환경에서 도구를 호출하여 모델의 컨텍스트 창에 대한 중간 결과의 영향을 줄입니다. 이를 통해 루프, 조건문, 데이터 변환과 같은 오케스트레이션 로직을 Python으로 구현할 수 있습니다.
*   **도구 사용 예제 (Tool Use Examples)**: 스키마 정의만으로는 전달하기 어려운 도구 사용 패턴을 보여주기 위한 보편적인 표준을 제공합니다. 이를 통해 Claude는 언제 선택적 매개변수를 포함해야 하는지, 어떤 조합이 유효한지 등을 학습할 수 있습니다.

이러한 기능들은 Claude for Excel과 같은 복잡한 애플리케이션을 구축하는 데 도움이 되며, AI 에이전트가 방대한 양의 데이터를 처리하고 여러 도구를 효율적으로 오케스트레이션할 수 있도록 지원합니다. 자세한 내용은 원문에서 확인하세요.
