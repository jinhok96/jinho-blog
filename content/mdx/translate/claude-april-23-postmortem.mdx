Anthropic은 최근 Claude Code의 품질 저하 보고를 조사한 결과, 세 가지 별개의 변경 사항이 원인이었음을 확인했으며 해당 문제들은 모두 해결되었습니다. API는 이번 문제의 영향을 받지 않았습니다.

- **Claude Code의 기본 추론 노력 변경:** 지연 시간을 줄이기 위해 추론 노력을 'high'에서 'medium'으로 변경했으나, 사용자의 피드백을 반영하여 'high'로 복구했습니다.
- **세션 비활성화 시 이전 추론 기록 삭제 버그 수정:** 세션이 장시간 비활성화된 후 재개 시 이전 추론 기록을 한 번만 삭제해야 했으나, 매 턴마다 삭제되는 버그를 수정했습니다.
- **응답 길이 제한을 위한 시스템 프롬프트 변경:** 응답의 장황함을 줄이기 위해 시스템 프롬프트에 길이 제한을 추가했으나, 코드 품질에 부정적인 영향을 미쳐 해당 변경 사항을 롤백했습니다.

앞으로는 내부 직원들이 실제 배포될 버전과 동일한 Claude Code 빌드를 사용하고, 시스템 프롬프트 변경에 대한 통제 강화, 광범위한 평가, 점진적 출시 등을 통해 유사한 문제가 발생할 가능성을 최소화할 것입니다. 자세한 내용은 원문에서 확인하세요.
