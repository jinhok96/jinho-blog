- Claude Code에서 Pro, Max, Team 플랜 사용자는 8월 14일부터 새로운 세션에 자동 모드가 기본값으로 적용됩니다.
- 자동 모드는 사용자의 원치 않는 중단을 방지하면서도 파괴적이거나 환경 외부를 대상으로 하는 위험한 작업을 차단하도록 설계되었습니다.
- 다양한 테스트 결과, 자동 모드는 수동 검토보다 안전하거나 더 나은 성능을 보였으며, 사용자는 약 25% 더 많은 PR을 생성하는 등 생산성이 향상되었습니다.
- 어도비, 뉴로, 거스터, 가너 헬스 등 여러 팀에서 이미 자동 모드를 프로덕션 기본값으로 사용하고 있습니다.
- Enterprise 플랜 및 Claude API 사용자에게는 자동 모드가 현재 옵트인으로 유지되며, 곧 기본값으로 전환될 예정입니다.
