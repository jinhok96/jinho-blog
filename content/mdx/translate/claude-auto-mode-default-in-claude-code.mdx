> 원문: [Auto mode is now the default in Claude Code for Pro, Max, and Team plans](https://claude.com/resources/articles/auto-mode-default-in-claude-code) — Claude Blog
> 이 글은 원문의 핵심 내용을 요약한 것입니다. 저작권은 원문 저자에게 있으며, 자세한 내용은 원문에서 확인하세요.

- Claude Code의 Pro, Max, Team 플랜에서 8월 14일부터 자동 모드가 기본값으로 설정됩니다.
- 자동 모드는 사용자의 개입 없이도 안전하고 효율적인 작업 수행을 지원하며, 기존 수동 검토보다 더 안전하다는 연구 결과가 있습니다.
- 특히 Prompt Injection 공격에 대한 방어 능력이 향상되었으며, 실제 사용 사례에서도 유해한 작업을 방지한 경험이 있습니다.
- Adobe, Nuro 등 다수의 기업에서 이미 자동 모드를 프로덕션 환경의 기본값으로 사용하고 있습니다.
- Enterprise 플랜 및 Claude API 사용자는 향후 자동 모드를 기본값으로 전환할 예정이며, 관리자는 설정을 통해 모드를 제어할 수 있습니다.
