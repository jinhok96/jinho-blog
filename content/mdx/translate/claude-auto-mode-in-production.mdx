Claude Code의 자동 모드가 기본 설정으로 변경되었습니다. 이제 에이전트가 실행하려는 모든 명령을 일일이 승인할 필요 없이, 분류기가 각 작업을 평가하여 잠재적으로 유해한 작업을 차단합니다.

자동 모드는 개발 속도와 안전성 사이의 균형을 맞추는 에이전트 코딩의 오랜 과제를 해결합니다. 모든 명령을 검토하는 것은 인간의 개입을 유지하지만, 세션이 길어지거나 병렬로 늘어나면 검토 자체가 병목 현상이 됩니다. 반면, 허가 절차를 완전히 생략하면 속도는 빨라지지만 프롬프트 주입, 범위 이탈, 프로덕션 리소스 삭제 등의 위험이 발생할 수 있습니다.

자동 모드는 이러한 간극을 상당 부분 메웁니다. 내부 평가 결과, 분류기는 수동으로 허가 프롬프트를 클릭하는 개발자보다 더 많은 위험한 작업을 탐지했으며, 외부 레드팀 평가에서도 우수한 성능을 보였습니다. 또한, 이전 기본 설정보다 세션 중단이 줄어들어 Claude는 중단 없이 9배 더 길게 작업할 수 있게 되었습니다.

Nuro, Gusto, Garner Health의 팀들은 자동 모드를 통해 프로덕션 환경에서 속도와 안전성을 동시에 확보하는 방법을 공유했습니다.

*   **Nuro**에서는 자동 모드를 활용하여 하루 종일 실행되는 연구 에이전트 작업을 지원하며, 이는 평가 지표를 개선하는 데 큰 도움이 됩니다.
*   **Gusto**는 자동 모드를 통해 반복적인 승인 절차를 제거하고 생산성을 향상시켰으며, 자동 모드는 적시에 작업을 차단하여 안전성을 유지합니다.
*   **Garner Health**는 자동 모드를 통해 엔지니어링 조직 전체의 표준화된 SDLC를 구축하고, 직원들은 자동 모드 덕분에 에이전트를 장시간 모니터링할 필요가 없어졌습니다.

코드 예시:
```typescript
// Example of a hook for interactive mode, now superseded by auto mode
const useApproval = (action: Action) => {
  const [approved, setApproved] = useState(false);
  const [pending, setPending] = useState(true);

  useEffect(() => {
    if (pending) {
      showApprovalPrompt(action, () => {
        setApproved(true);
        setPending(false);
      }, () => {
        setPending(false);
      });
    }
  }, [pending, action]);

  return { approved, pending };
};
```
