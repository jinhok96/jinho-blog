MCP(Model Context Protocol)의 다섯 번째 사양인 MCP 2026-07-28이 출시되었습니다. 이번 업데이트는 MCP를 무상태 핵심(stateless core)으로 전환하고, 인증을 강화하며, 공식 확장 기능을 졸업시켰습니다. 이러한 변경 사항은 Claude 제품 전반에 걸쳐 적용됩니다.

주요 변경 사항은 다음과 같습니다.

-   **무상태 핵심 (Stateless core):** 기존의 양방향 상태 유지 프로토콜에서 요청/응답 모델로 변경되어 서버리스 및 엣지 인프라에 배포가 용이해졌습니다.
-   **표준화된 확장 기능 (Standardized extensions):** MCP Apps 및 Tasks가 버전 관리되는 확장 기능 프레임워크 하에 제공되어, 핵심 프로토콜 변경 없이도 인터랙티브 UI 및 장기 실행 작업과 같은 기능을 추가할 수 있게 되었습니다.
-   **강화된 인증 (Auth hardening):** OAuth 2.0 및 OIDC 표준에 맞춰 인증 기능이 강화되어, 엔터프라이즈 ID 시스템과의 연동이 간편해졌습니다.

Claude는 950개 이상의 MCP 서버를 커넥터 디렉토리에 등록했으며, MCP Apps, 엔터프라이즈 관리 인증, 개발자 관찰 기능 등을 통해 MCP의 개발 및 배포를 지원하고 있습니다. 또한, 프라이빗 네트워크 내 MCP 서버 연결을 위한 MCP 터널(연구 미리보기) 기능도 제공합니다.
