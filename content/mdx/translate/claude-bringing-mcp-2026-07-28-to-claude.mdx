MCP 2026-07-28은 모델 컨텍스트 프로토콜(MCP)의 다섯 번째 사양 릴리스로, 상태 비저장 코어로 전환하고 인증을 강화하며 공식 확장을 정식 출시합니다.

*   **상태 비저장 코어:** MCP는 양방향 상태 유지 프로토콜에서 요청/응답 모델로 변경되어 서버리스 및 엣지 인프라 배포를 단순화합니다.
*   **표준화된 확장 기능:** MCP Apps 및 Tasks는 버전이 지정된 확장 프레임워크를 통해 핵심 프로토콜 변경 없이 UI 및 장기 실행 작업과 같은 기능을 추가할 수 있습니다.
*   **인증 강화:** OAuth 2.0 및 OIDC 표준을 준수하여 Entra 또는 Okta와 같은 엔터프라이즈 ID 시스템과의 연동을 지원합니다.
*   **Claude 내 지원 강화:** MCP Apps, 엔터프라이즈 관리 인증, 개발자 관찰 기능, MCP 터널(연구 미리 보기)을 통해 Claude에서 MCP 서버를 더욱 쉽게 구축하고 배포할 수 있습니다.
