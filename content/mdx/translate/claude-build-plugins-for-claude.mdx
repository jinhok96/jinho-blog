Claude는 수백만 명의 사용자와 앱, 작업 도구, 데이터를 연결하며, 개발자들이 이러한 사용자에게 더 쉽게 도달할 수 있도록 플러그인 구축 기능을 제공합니다. 플러그인은 MCP 커넥터, Agent Skills 또는 둘 다를 패키징하며 Claude를 위한 서드파티 확장 기능을 구축하는 주요 방법입니다.

*   **플러그인 제출 및 추적:** 유료 Claude 플랜 사용자는 새로운 디렉토리 제출 포털을 통해 플러그인을 제출하고 관리할 수 있습니다. 단일 MCP 커넥터 또는 GitHub에 호스팅된 MCP 서버와 스킬을 포함하는 플러그인 번들을 제출할 수 있습니다. 포털은 플러그인의 자동 유효성 검사, 검토 상태 및 피드백 확인, 원하는 시점의 게시까지 안내합니다.
*   **게시 후 모니터링 및 개선:** 플러그인이 출시되면, 사용량 분석을 통해 설치 현황을 파악하고 검색 노출도를 확인하여 개선할 수 있습니다.
*   **MCP 2.0 및 확장 기능 활용:** Claude는 상태 비저장 코어를 포함한 MCP 2.0 사양을 지원합니다. MCP Apps를 통해 채팅 내 대화형 UI를 제공하거나, Enterprise Managed Auth로 제로터치 OAuth를 구현하여 사용자 경험을 향상시킬 수 있습니다.
*   **플러그인 생태계 확장:** 기존 스킬, 커넥터, 플러그인은 계속 지원되며, 향후 커넥터 목록을 플러그인으로 전환할 수 있게 될 예정입니다.
