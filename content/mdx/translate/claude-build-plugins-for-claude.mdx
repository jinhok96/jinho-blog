*   **새로운 개발자 포털 개설:** 이제 개발자들은 새로운 포털을 통해 Claude 플러그인을 제출하고, 검토 과정을 추적하며, 출시 후 사용량 분석 데이터를 확인할 수 있습니다.
*   **다양한 제출 방식 지원:** 단일 MCP 커넥터 또는 MCP 서버와 스킬을 결합한 플러그인 번들 형태로 제출할 수 있으며, Claude Code에서는 LSP, 명령, 훅, 에이전트 포함도 가능합니다.
*   **자동 검증 및 피드백 제공:** 제출 시 플러그인이 자동으로 검증되고 안전성 검사를 거치며, 검토 상태 및 개선 사항에 대한 피드백을 받을 수 있어 문제를 조기에 발견할 수 있습니다.
*   **MCP 2.0 및 확장 기능 지원:** Claude는 상태 비저장 코어를 포함하는 MCP 2.0 사양을 지원하며, 대화 내 상호작용 UI를 위한 MCP Apps와 기업 사용자를 위한 Enterprise Managed Auth를 제공합니다.
