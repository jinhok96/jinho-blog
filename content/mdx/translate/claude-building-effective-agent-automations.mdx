> 이 글은 원문의 핵심 내용을 요약한 것입니다. 저작권은 원문 저자에게 있으며, 자세한 내용은 원문에서 확인하세요.

Anthropic은 Claude Managed Agents(베타)를 활용하여 사용자 지정 소스(Slack, GitHub 등)에서 정기적으로 정보를 수집하고 변경 사항을 추적한 후 필요한 정보를 알려주는 효과적인 에이전트 자동화 구축 방법을 제시합니다. 이 시스템은 다음과 같은 핵심 요소로 구성됩니다.

-   **소스(Sources):** Slack 채널 및 GitHub 저장소와 같은 데이터를 읽어오는 위치를 지정합니다. Managed Agents를 통해 Vault에 안전하게 저장된 자격 증명을 사용하여 각 소스에서 마지막으로 읽은 시점을 기록하는 북마크 기능을 통해 누락이나 중복 없이 정확하게 데이터를 수집합니다.
-   **대상(Destination):** 에이전트가 수집된 정보를 전달할 단일 대상(예: Slack 채널)을 설정합니다. 정보가 실제로 게시되었는지 확인한 후에만 북마크와 기록을 업데이트하여 이중 게시나 정보 누락을 방지합니다.
-   **에이전트(Agent):** 모델, 도구, 프롬프트 및 실행 단계를 정의하는 `agent.md` 파일을 통해 에이전트의 동작 방식을 설정합니다. 간결성과 정확성을 위해 최신 정보를 실시간으로 다시 확인하고, 에이전트가 자체적으로 결정을 내리지 않도록 제어합니다.
-   **일정(Schedule):** `deployment.md` 파일을 통해 에이전트 실행 일정을 정의합니다. 지정된 시간대에 맞춰 에이전트가 자동으로 실행되며, 필요에 따라 수동으로 테스트 실행도 가능합니다.
-   **메모리(Memory):** 사용자의 기본 설정(Preferences)과 에이전트 자체의 상태(State)를 관리합니다. 에이전트는 매 실행마다 최신 설정을 읽고, 보고한 항목에 대한 원장(Ledger)을 유지하여 정보의 일관성을 보장합니다.
-   **가드레일(Guardrails):** 에이전트의 액세스 권한을 최소화하고, 예기치 않은 비용 발생을 막기 위한 예산(Budget) 제한을 설정합니다.

이 글에서는 `ant apply` 명령어를 사용하여 에이전트, 환경, 메모리 저장소, Vault 및 배포 구성을 생성하고 관리하는 방법을 설명하며, Claude Code를 통해 이 모든 과정을 대화형으로 따라갈 수 있도록 안내합니다.
