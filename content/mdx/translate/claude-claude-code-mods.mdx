Claude Code는 이제 TypeScript 함수인 'mods'를 통해 사용자 정의가 가능합니다. Mods는 프롬프트 재작성, UI 추가, 내장 기능 대체, 새로운 기능 추가 등 Claude Code의 작동 방식을 변경할 수 있습니다. 직접 작성하거나 Claude Code에게 작성을 요청할 수도 있습니다. Mods는 플러그인 형태로 배포되며, CLI 및 데스크톱 앱에서 작동합니다.

*   **핵심 기능:** Mods는 Claude Code의 이벤트에 후킹하여 프롬프트 재작성, 도구 호출 제어, 권한 요청 처리, UI 변경 등 다양한 작업을 수행할 수 있습니다.
*   **유연한 제어:** Mods를 통해 사용자는 Claude Code를 자신의 작업 방식에 맞게 조정할 수 있으며, 일부 내장 기능은 Mods 형태로 제공되어 비활성화하거나 자체 버전으로 대체할 수 있습니다.
*   **팀 및 엔터프라이즈 기능:** Mods는 플러그인으로 관리되어 관리자가 설치를 제어할 수 있으며, `sec-default` 모드를 통해 보안을 강화하거나 자체 보안 및 감사 모드를 구축할 수 있습니다.
*   **개발자 지원:** Mods 개발을 위한 가이드 및 문서를 제공하며, Claude Code 자체를 사용하여 Mods를 생성하고 설치할 수도 있습니다.
*   **새로운 가능성:** CI/CD 상태 표시, 프로덕션 환경 안전 장치, 감사 로깅 등 팀별 맞춤형 기능 구현을 지원합니다.
