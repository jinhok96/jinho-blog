Claude Code는 이제 TypeScript 함수인 'mods'를 통해 기능 확장이 가능해졌습니다. Mods는 프롬프트 재작성, UI 추가, 내장 기능 대체, 새로운 기능 추가 등 다양한 방식으로 Claude Code의 동작을 변경할 수 있습니다. 직접 작성하거나 Claude Code에게 생성을 요청할 수 있으며, 플러그인 형태로 설치 및 공유됩니다.

*   **Mods의 주요 기능:**
    *   모델에 전달되기 전 프롬프트 수정
    *   툴(Tool) 호출 차단, 재작성 또는 재시도
    *   권한 요청 승인 또는 거부
    *   툴 결과에서 민감 정보 제거
    *   Claude Code 인터페이스 편집 또는 교체, 버튼 및 입력 필드 추가

*   **내장 기능 커스터마이징:** `/diff`와 같은 일부 내장 기능이 Mods로 전환되어, 사용자가 기능을 비활성화하거나 자신만의 버전으로 대체할 수 있습니다. 향후 더 많은 내장 기능이 Mods 형태로 제공될 예정입니다.

*   **팀 및 엔터프라이즈 기능:** Mods는 플러그인 형태로 제공되므로 기존 플러그인 정책이 적용됩니다. Team 및 Enterprise 플랜에서는 관리자가 플러그인 마켓플레이스를 제어하고, `sec-default`라는 기본 보안 Mods가 로드되어 사용자 설치 Mods의 위험한 동작을 제한합니다.

*   **시작하기:** Mods는 Claude Code CLI 및 데스크톱 앱에서 오늘부터 사용할 수 있습니다. Claude 디렉토리에서 Mods를 포함한 플러그인을 설치하거나 `/plugin` 명령어로 설치할 수 있습니다. Mods 개발을 위한 가이드 및 문서를 제공합니다.
