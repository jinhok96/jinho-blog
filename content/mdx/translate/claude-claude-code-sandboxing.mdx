Claude Code는 코드 작성, 테스트, 디버깅을 돕는 도구로, 코드베이스 접근 및 파일 수정 권한이 필요합니다. 이를 악용한 프롬프트 주입 공격 위험을 줄이고자 새로운 보안 기능이 도입되었습니다.

-   **Sandboxed bash tool**: 컨테이너 없이 디렉토리 및 네트워크 접근을 제어하는 새로운 샌드박스 런타임이 베타 출시되었습니다. 이를 통해 Claude Code는 권한 프롬프트 없이 안전하게 명령을 실행하고, 샌드박스 외부 접근 시도 시 사용자에게 알립니다.
-   **Filesystem isolation**: Claude가 특정 디렉토리만 접근하거나 수정하도록 제한하여 민감한 시스템 파일 변조를 방지합니다.
-   **Network isolation**: Claude가 승인된 서버에만 연결하도록 하여 민감 정보 유출이나 악성코드 다운로드를 차단합니다.
-   **Claude Code on the web**: 클라우드에서 Claude Code를 격리된 샌드박스 환경에서 실행할 수 있게 되어, Git 자격증명 등 민감 정보가 샌드박스 내부에 노출되지 않도록 합니다.

이러한 기능들은 개발 생산성과 보안을 동시에 향상시키며, 오픈소스로 공개되어 다른 개발팀에서도 활용할 수 있습니다.
