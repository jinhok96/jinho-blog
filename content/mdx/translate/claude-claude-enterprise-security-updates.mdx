Claude Enterprise는 보안 팀을 위해 다음과 같은 새로운 기능들을 도입하여 가시성과 제어 기능을 강화했습니다.

-   **보안 센터**: 조직의 Claude 설정이 Anthropic 권장 구성과 어떻게 비교되는지 한곳에서 검토하고, 감사 및 이해관계자와 공유할 보고서를 다운로드할 수 있습니다.
-   **추론 후킹(Inference Hooks)**: 프롬프트 후킹과 사전 도구 호출 후킹을 통해 프롬프트 및 도구 호출이 조직의 데이터 보안 도구에서 검사되도록 연결하여 DLP 및 보안 정책을 적용합니다.
-   **중앙 집중식 관리**: 회사 전체 설정을 위한 단일 관리 콘솔을 제공하며, 여러 ID 공급자를 연결하고 조직 간 설정을 일관되게 관리할 수 있습니다.
-   **접근 제어 강화**: Admin API를 통해 사용자를 로그아웃시키고, IP 허용 목록을 직접 관리하며, 관리 대상 컴퓨터의 Claude Desktop에서 개인 계정을 차단하여 섀도우 IT를 방지할 수 있습니다.
-   **EDR 통합**: Cowork 및 통합 Claude의 가상 머신 내에서 조직의 EDR 센서를 실행하여 보안 팀이 모든 엔드포인트에서와 동일한 수준의 가시성을 확보할 수 있습니다.
