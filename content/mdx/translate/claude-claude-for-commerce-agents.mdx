Anthropic은 기업이 Claude를 사용하여 AI 기반 커머스 에이전트를 구축하도록 돕는 새로운 청사진을 출시했습니다. 이 청사진은 쇼핑 에이전트와 판매자 에이전트의 구현을 포함하며, Claude API, Amazon Bedrock, Microsoft Foundry, Google Cloud Vertex AI와 같은 기존 개발 환경에서 사용할 수 있습니다.

- **쇼핑 에이전트:** 고객의 언어 이해, 상품 검색, 비교, 장바구니 생성, 주문 내역 기반의 고객 서비스 응답 등을 지원합니다.
- **판매자 에이전트:** 판매 성과 분석, 재고 관리, 가격 및 프로모션 추천, 마케팅 캠페인 초안 작성 등을 통해 판매자를 지원합니다.
- **고객 경험 개선:** 실제 사용 사례에서 장바구니 규모 35% 증가, 구매 완료율 60% 향상 등의 성과를 보였습니다.
- **파트너십:** Accenture, Mastercard, Visa 등 다양한 파트너와 협력하여 솔루션을 제공합니다.
- **청사진 접근:** GitHub에서 코드를 이용 가능하며, 데모와 엔지니어링 심층 분석 자료도 함께 제공됩니다.
