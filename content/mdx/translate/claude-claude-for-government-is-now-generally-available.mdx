> 원문: [Claude for Government is now generally available](https://claude.com/blog/claude-for-government-is-now-generally-available) — Claude Blog
> 이 글은 원문의 핵심 내용을 요약한 것입니다. 저작권은 원문 저자에게 있으며, 자세한 내용은 원문에서 확인하세요.

-   **Claude for Government 일반 공급:** 연방 및 주 정부 기관을 대상으로 FedRAMP High 환경에서 Claude의 코딩 및 에이전트 작업 기능을 제공합니다.
-   **주요 기능:** 기관 직원은 파일과 직접 상호작용하며 업무를 처리하고, Claude Code를 통해 소프트웨어 시스템을 구축 및 현대화할 수 있습니다.
-   **강화된 거버넌스 및 관리:** 좌석별 요금 없이 사용량 기반 과금, 기관별 지출 및 모델 제한 설정, 감사 로그, 자체 ID 공급자 연동 등의 기능을 제공합니다.
-   **Claude Code CLI 및 Claude for Microsoft 365 조기 액세스:** 동일한 환경 및 관리 제어 하에 Claude Code CLI와 Claude for Microsoft 365가 조기 액세스로 출시되었습니다.
