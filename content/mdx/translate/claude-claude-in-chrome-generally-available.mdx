Claude in Chrome이 모든 유료 Claude 요금제에서 일반적으로 사용할 수 있게 되었습니다. 이제 Claude는 매번 승인을 받지 않고도 브라우저에서 자율적으로 작업을 수행할 수 있습니다. 각 작업은 수행 전에 안전성 분류기를 통해 검증되어 안전하고 요청에 부합하는지 확인합니다.

- Claude in Chrome은 사용자의 로그인 정보를 활용하여 웹 페이지를 보고 텍스트를 읽고 입력하거나, 링크를 클릭하고, 페이지 간을 탐색하며, 양식을 작성하는 등 브라우저 작업을 수행할 수 있습니다.
- 프롬프트 주입 공격으로부터 보호하기 위해 Claude의 방어 체계를 개선했으며, 새로운 공격에 대한 인식 능력을 향상시키고 웹 콘텐츠를 Claude가 처리하기 전에 검사하는 '프로브'를 도입했습니다.
- Claude는 이제 안전하다고 판단되는 작업을 자동으로 승인하며, 이러한 작업은 사용자 요청과 일치하는지 확인하는 분류기를 거칩니다.
- 최신 평가에서 Claude Sonnet 5, Opus 5, Mythos 5는 프로브 및 안전 분류기와 함께 실행될 때 프롬프트 주입 공격이 성공하지 못했으며, Fable 5의 경우 0.3%의 낮은 성공률을 보였습니다.
- Claude in Chrome을 사용하려면 Chrome 웹 스토어에서 설치해야 합니다. 파일 작업이나 다른 애플리케이션과의 연동은 Claude 데스크톱 앱을 사용해야 합니다.
