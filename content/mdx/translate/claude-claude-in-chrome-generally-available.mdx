- Claude in Chrome이 모든 유료 Claude 플랜에 걸쳐 정식 출시되었습니다.
- 이제 Claude는 매번 승인 요청 없이도 브라우저에서 자율적으로 작업을 수행할 수 있게 되었습니다.
- 각 작업은 안전하고 요청과 일치하는지 확인하기 위한 안전 분류기가 실행 전에 검증합니다.
- Claude in Chrome은 사용자의 기존 로그인 정보를 활용하여 웹 페이지를 보고 텍스트 읽기, 링크 클릭, 페이지 이동, 양식 입력 등의 작업을 수행할 수 있습니다.
- 특히, 내부 대시보드, 레거시 시스템, 공급업체 포털 등 기존 도구와 연결되지 않는 곳에도 Claude가 접근할 수 있도록 지원합니다.
