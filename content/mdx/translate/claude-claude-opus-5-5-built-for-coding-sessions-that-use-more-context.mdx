Claude Opus 5.5는 일반적인 토큰 기반 워크로드에서 Opus 5 대비 약 40% 저렴한 비용으로 실행될 수 있도록 설계되었습니다. 특히 개발자들이 최근 6개월간 더 많이 사용하는 길고 맥락이 풍부한 Claude Code 세션에서 비용 절감 효과가 두드러집니다.

Claude Code 사용 트렌드에 따르면, 개발자들은 더 많은 모델 호출과 2.6배 증가한 요청당 맥락(context per request)을 사용하며, 이는 더 크고 개방적인 작업에 Claude를 활용하는 경향을 보여줍니다.

Claude Opus 5.5의 비용 효율성 개선은 다음 세 가지 주요 변경 사항에 기인합니다.

- **가격 정책 변경**: 입력 및 출력 토큰 비용을 20% 인하했으며, 특히 캐시된 토큰 읽기 비용을 60% 대폭 인하했습니다. 이는 에이전트 및 코딩 작업의 주요 비용이 캐시 읽기에서 발생하기 때문입니다.
- **개선된 캐시 활용**: Claude Code 기능 개선으로 캐시 미스가 50% 이상 감소했으며, 캐시 수명을 1시간으로 설정하거나 하위 에이전트가 부모의 캐시를 상속받도록 하여 효율성을 높였습니다.
- **작업당 턴(turn) 감소**: Opus 5.5는 동일한 작업을 완료하는 데 더 적은 턴과 도구 호출을 필요로 하여, 특히 개방적인 작업에서 토큰 낭비를 줄입니다. 또한, Opus 5.5는 Opus 5보다 30% 이상 빠른 출력 속도를 제공합니다.

효율적인 스케일링을 위해 캐시된 읽기 비율을 높이는 것이 중요합니다. 이를 위해 세션 중간에 모델을 변경하지 않고, 미리 맥락을 압축하며, API 키 또는 클라우드 공급자를 사용하는 경우 1시간 캐시 수명을 설정하는 습관을 권장합니다.
