Claude Opus 5.5는 기존 Opus 5 대비 약 40% 저렴한 비용으로 실행 가능하며, 특히 개발자들이 늘리고 있는 길고 복잡한 코딩 세션에서 이러한 비용 절감 효과가 두드러집니다. 이는 다음과 같은 주요 변화 덕분입니다.

*   **캐시 사용의 경제성 증대**: 입력 및 출력 토큰 비용은 20% 인하되었고, 특히 에이전트 및 코딩 작업에서 가장 큰 비중을 차지하는 캐시 토큰 읽기 비용은 60% 대폭 인하되었습니다.
*   **향상된 캐시 활용 능력**: Claude Code는 최근 6개월간 추가된 기능 덕분에 캐시 미스율을 50% 이상 감소시켰으며, 세션 중 모델 변경이나 도구 로딩 시에도 캐시가 유지됩니다.
*   **작업당 소요 턴 수 감소**: Opus 5.5는 동일한 작업을 더 적은 턴 수로 완료할 수 있어, 특히 복잡하고 개방적인 작업에서 토큰 낭비를 줄여 비용 효율성을 높입니다. 또한, 출력 속도도 30% 이상 빨라져 긴 세션에서의 대기 시간을 줄입니다.

효율적인 코딩을 위해 모델 변경을 최소화하고, 캐시 압축을 미리 수행하며, API 사용자나 클라우드 제공업체의 경우 1시간 캐시 수명을 설정하는 것이 권장됩니다. 자세한 내용은 원문에서 확인하세요.
