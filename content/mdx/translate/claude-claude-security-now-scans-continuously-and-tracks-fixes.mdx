Claude Security가 출시 이후 100만 건 이상의 취약점을 발견했으며, 이제 실시간 코드 변경 사항을 지속적으로 스캔하고 발견된 취약점의 수정 여부를 자동으로 추적하는 기능을 제공합니다.

- **지속적인 모니터링:** 코드 변경 시점에 맞춰 자동으로 스캔을 실행하여 최신 상태를 유지합니다. GitHub, GitLab 등 다양한 Git 제공 업체와 연동 가능하며, 여러 저장소를 하나의 프로젝트로 관리하여 서비스 간의 잠재적 문제를 포착합니다.
- **자동 수정 사항 추적:** 발견된 취약점이 수정되면 자동으로 '수정됨'으로 표시되며, 이후 다시 발견될 경우 자동으로 재오픈됩니다.
- **환경별 맞춤 정보 반영:** 각 환경에 적용된 보안 정책, 코드 배포 방식 등 팀의 지식을 입력하여 Claude Security가 더 정확하게 보안 위험을 평가하고, 이미 처리된 위험은 제외하도록 합니다.
- **API 연동 및 워크플로우 통합:** 새로운 API를 통해 Claude Security를 기존 워크플로우에 통합하고, 웹훅으로 시스템 알림을 받을 수 있습니다. Claude.ai 및 Claude Code에서도 사용 가능하며, 역할 기반 접근 제어를 통해 접근 권한을 세밀하게 관리할 수 있습니다.
