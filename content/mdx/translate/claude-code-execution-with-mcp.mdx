Model Context Protocol (MCP)은 AI 에이전트를 외부 시스템에 연결하기 위한 개방형 표준입니다. MCP는 에이전트가 수많은 도구와 상호작용할 수 있도록 하지만, 연결된 도구가 많아질수록 도구 정의와 중간 결과가 컨텍스트 창에 과도하게 소모되어 에이전트 효율성이 저하됩니다.

코드 실행 환경을 활용하면 MCP 서버를 직접적인 도구 호출 대신 코드 API로 제공할 수 있습니다. 이를 통해 에이전트는 다음과 같은 이점을 얻습니다.

*   **효율적인 컨텍스트 사용**: 필요한 도구만 온디맨드로 로드하고, 모델에 전달하기 전에 데이터를 필터링 및 변환하여 토큰 소모를 크게 줄입니다 (예: 150,000 토큰에서 2,000 토큰으로 98.7% 절감).
*   **진행적 공개**: 파일 시스템을 탐색하듯 도구를 점진적으로 로드하여 컨텍스트 창을 절약합니다.
*   **강력하고 컨텍스트 효율적인 제어 흐름**: 루프, 조건문, 오류 처리를 코드로 직접 수행하여 도구 호출 체인을 단순화하고 지연 시간을 줄입니다.
*   **개인 정보 보호**: 중간 결과가 실행 환경 내에 유지되어 민감한 데이터가 모델 컨텍스트에 노출되는 것을 방지하며, PII 토큰화 기능도 지원합니다.
*   **상태 지속성 및 스킬**: 코드를 파일에 저장하여 에이전트가 상태를 유지하고 재사용 가능한 함수(스킬)를 구축할 수 있도록 합니다.

코드 실행은 강력한 이점을 제공하지만, 보안 샌드박싱, 리소스 제한, 모니터링과 같은 추가적인 인프라 요구 사항과 운영 오버헤드를 수반합니다. 자세한 내용은 원문에서 확인하세요.
