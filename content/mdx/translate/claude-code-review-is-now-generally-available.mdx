> 원문: [Code Review is now generally available](https://claude.com/resources/articles/code-review-is-now-generally-available) — Claude Blog
> 이 글은 원문의 핵심 내용을 요약한 것입니다. 저작권은 원문 저자에게 있으며, 자세한 내용은 원문에서 확인하세요.

- Claude 코드 리뷰 기능이 연구 미리 보기 단계를 마치고 Claude Team 및 Enterprise 고객에게 정식으로 제공됩니다.
- 코드 리뷰는 더 빨라졌으며, 중요한 버그를 더 잘 찾아내고 각 리포지토리에 맞춰 조정하기 쉬워졌습니다.
- 리뷰 속도가 3배 빨라졌고(평균 20분에서 6-10분), 문제점, 트리거, 수정 방법을 명확하고 간결하게 설명하는 고품질 리뷰를 제공합니다.
- 관리자는 리포지토리별로 Quick, Standard, Deep 옵션을 선택하여 리뷰 깊이를 조절할 수 있습니다.
