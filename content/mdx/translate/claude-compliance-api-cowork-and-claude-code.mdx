Claude Compliance API가 Cowork (데스크톱, 웹, 모바일) 및 Claude Code (CLI, 데스크톱)까지 지원 범위를 확장했습니다.

-   Claude Cowork 및 Claude Code 세션의 콘텐츠와 메타데이터를 기존 Compliance API 인터페이스를 통해 가져올 수 있습니다.
-   새로운 엔드포인트는 기존 데이터 수집에 영향을 주지 않으며, 별도의 로깅 인프라 구축 없이 Claude 사용 현황을 파악할 수 있도록 돕습니다.
-   각 세션은 프롬프트, 응답, 도구 활동을 포함하는 통합된 세션 기록과 사용자 ID, 조직 ID 등의 메타데이터를 함께 제공합니다.
-   현재 Claude Code 웹 버전, Claude Platform을 통한 Claude Code, Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry 세션은 베타 지원 범위에 포함되지 않습니다.
-   기존 OpenTelemetry 데이터를 사용하는 경우, 추가적인 인프라 설정 없이 Compliance API와 함께 사용할 수 있습니다.
