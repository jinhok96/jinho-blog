Claude Compliance API가 Cowork(데스크톱, 웹, 모바일) 및 Claude Code(CLI, 데스크톱 앱) 세션에 대한 지원을 베타로 확장했습니다.

-   **기능 확장**: Claude Cowork와 Claude Code의 세션 콘텐츠 및 메타데이터를 기존 Claude 채팅 데이터와 동일한 Compliance API 인터페이스를 통해 액세스할 수 있습니다.
-   **데이터 통합**: 새 엔드포인트는 각 Cowork 및 Claude Code 세션에 대한 통합된 트랜스크립트를 반환하여 프롬프트, 응답 및 도구 활동을 단일 세션 기록으로 제공합니다.
-   **포함 데이터**: 세션 콘텐츠(프롬프트, 응답, 도구 호출, 스킬, 아티팩트)와 세션 메타데이터(사용자 ID, 조직 ID, 세션 ID, 타임스탬프)를 모두 포함합니다.
-   **현재 베타 범위**: Claude Code 웹, Claude Platform을 통한 Claude Code, Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry에서의 세션은 현재 베타에 포함되지 않습니다.
-   **기존 환경과의 호환성**: OpenTelemetry 데이터 내보내기를 사용 중인 경우, 별도의 인프라 없이 Compliance API와 함께 계속 사용할 수 있습니다.
