AI 에이전트 메모리는 사용자와의 상호작용 및 과제 수행을 통해 Claude가 얻는 지식을 저장하고, 이를 나중에 참조할 수 있도록 하는 시스템입니다. 이는 모델의 가중치 변경, 인컨텍스트 학습, 또는 컴팩션과 같은 다른 지식 관리 방식과는 구분됩니다.

-   **메모리는 미래를 위한 예측입니다.** 에이전트가 규칙을 기록하는 것은 미래 세션에서 해당 패턴이 다시 관련될 것이라는 예측이며, 검증된 사실을 기록하는 것은 향후 세션에서 해당 사실을 재확인 없이 신뢰할 수 있을 것이라는 예측입니다.
-   **Claude는 중요도를 판단하는 능력을 학습했습니다.** Pokémon Red 플레이와 같은 장기 과제에서, Claude는 어떤 정보가 기억할 가치가 있는지 판단하는 능력을 향상시켰습니다. 단순히 모든 것을 기록하는 대신, 전략, 계획, 테스트된 규칙 등 에이전트가 스스로 알아낸 정보에 집중하여 효율적인 메모리 관리를 수행합니다.
-   **'드림'은 메모리를 수정하고 새로운 표현을 구축할 수 있습니다.** '드림' 과정을 통해 Claude는 기록된 메모리를 세션 기록과 비교하여 오류를 수정하고, 위키와 같은 새로운 메모리 표현을 생성하여 방대한 지식 기반을 효과적으로 탐색할 수 있습니다.
-   **'드림'은 메모리 계층 구조를 승격시키고 목표를 집중시킬 수 있습니다.** '드림'은 중요한 메모리를 메모리 계층의 상위로 올려 세션 시작 시 자동으로 로드되도록 하며, 특정 목표를 중심으로 메모리가 구성되도록 조정할 수 있습니다.
-   **'드림'은 세션에서 남겨진 격차를 메울 수 있습니다.** '드림'은 여러 세션에 걸쳐 공통 패턴을 찾거나 일반적인 실수를 수정하며, 생성되지 않은 페이지로 연결되는 링크를 기존 페이지로 재지정하거나 새로운 인덱스 페이지를 추가하여 메모리의 완성도를 높입니다.
