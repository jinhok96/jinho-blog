Claude Platform에서 컴퓨터 사용(Computer use), Skills API, Files API가 정식 출시되었습니다. 컴퓨터 사용 기능에는 웹 애플리케이션에서 작동하는 새로운 브라우저 사용 도구(browser use tool)가 추가되었습니다. 이러한 기능들은 에이전트가 소프트웨어를 조작하고, 팀의 전문성을 적용하며, 최종 결과 파일을 반환할 수 있도록 지원합니다.

새로운 기능들은 다음과 같습니다.

- **컴퓨터 사용 (Computer use):** 한 번의 모델 호출당 여러 작업을 수행할 수 있게 되어 작업 완료 시간이 단축되었으며, HIPAA 규제 워크로드에 대한 BAA 자격이 부여되었습니다.
- **브라우저 사용 도구 (Browser use tool):** 페이지 구조를 읽어 픽셀 대신 웹 요소(element)를 더 안정적으로 대상으로 삼을 수 있게 되었습니다.
- **Skills API:** 자체 스킬(skill)을 업로드하고 버전 관리하는 API가 간소화되었습니다.
- **Files API:** 파일 자동 만료, 5배 향상된 속도 제한(rate limits), 조직당 1TB 저장 공간을 제공합니다.

이 기능들을 통해 에이전트는 문서를 읽고, 팀의 절차를 따르며, 웹 포털에서 작업을 완료하고, 결과를 파일로 저장하는 등 복잡한 작업을 수행할 수 있습니다.
