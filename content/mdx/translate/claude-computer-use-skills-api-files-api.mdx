Claude Platform에서 컴퓨터 사용(Computer use), Skills API, Files API가 정식 출시되었습니다. 컴퓨터 사용 기능은 새로운 브라우저 사용 도구를 추가하여 에이전트가 웹 애플리케이션 내에서 작동할 수 있도록 합니다.

*   **컴퓨터 사용(Computer use)**: 에이전트가 스크린샷을 기반으로 클릭, 타이핑, 스크롤 등의 작업을 수행하여 자동화되지 않은 애플리케이션에서도 작동할 수 있게 합니다. 업데이트된 기능은 한 번의 모델 호출당 여러 작업을 수행하여 작업 완료 시간을 단축하며, HIPAA 규제 워크로드에도 적용 가능합니다.
*   **브라우저 사용 도구(Browser use tool)**: 컴퓨터 사용 기능의 확장으로, 페이지 구조 정보를 활용하여 픽셀 단위가 아닌 특정 웹 요소를 더 안정적으로 타겟팅할 수 있습니다.
*   **Skills API**: 팀의 전문 지식과 절차를 폴더 형태로 업로드하고 버전 관리할 수 있는 API입니다. Claude의 코드 실행 샌드박스에서 실행되므로 별도의 호스팅이 필요 없습니다.
*   **Files API**: 에이전트가 읽고 쓰는 문서를 위한 스토리지입니다. 파일을 한 번 업로드하고 ID로 참조하여 재전송을 줄일 수 있으며, 에이전트가 생성한 파일을 다운로드할 수 있습니다. 5배 높은 속도 제한과 조직당 1TB의 저장 공간을 제공합니다.

이러한 기능들을 통해 팀의 전문성을 코드로 정의하고, 복잡한 금융 문서 초안 생성과 같은 워크플로우를 자동화하는 데 활용할 수 있습니다.
