Claude Cowork 데스크톱 앱에 자체 브라우저 기능이 추가되었습니다. 이제 Claude는 사용자의 웹 브라우저 확장 프로그램이나 접근 없이도 웹 페이지를 탐색하고, 정보를 읽고, 클릭 및 입력을 수행할 수 있습니다. 이를 통해 사용자는 기존 작업을 계속하면서 Claude에게 웹 관련 업무를 위임할 수 있습니다.

-   **자체 브라우저 탑재**: Claude Cowork 데스크톱 앱 내부에 독립적인 브라우저가 내장되어 사용자의 브라우저와 분리됩니다.
-   **주요 기능**: 웹 페이지 탐색, 정보 추출(대시보드 숫자, 포털 데이터 등), 양식 작성 등 웹 기반 작업을 Claude가 직접 수행합니다.
-   **보안 및 제어**: 사용자의 탭, 북마크, 비밀번호는 Claude와 공유되지 않으며, 로그인 정보는 사이트별로 수동으로 가져와야 합니다. 민감한 사이트는 기본적으로 제외됩니다.
-   **기존 방식과의 차이**: 자체 브라우저는 사용자가 다른 작업을 하는 동안 웹 업무를 위임할 때 사용되며, Claude in Chrome 확장 프로그램은 사용자가 이미 열어둔 페이지에서 직접 작업할 때 사용됩니다.
-   **배포**: Pro, Max, Team 플랜 사용자에게 순차적으로 배포되며, Enterprise 플랜 관리자는 즉시 활성화할 수 있습니다.
