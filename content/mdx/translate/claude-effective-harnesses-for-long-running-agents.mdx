AI 에이전트가 점점 더 복잡한 작업을 수행하게 되면서, 수 시간에서 수일에 걸쳐 진행되는 작업에 대한 일관된 진척을 확보하는 것이 중요해지고 있습니다. 이는 각 세션마다 이전 작업 내용을 기억하지 못하는 에이전트의 한계 때문입니다.

Claude Agent SDK는 이러한 문제를 해결하기 위해 다음과 같은 두 가지 핵심 기능을 도입했습니다.

-   **초기화 에이전트**: 첫 실행 시 `init.sh` 스크립트, 작업 로그 파일 (`claude-progress.txt`), 초기 git 커밋을 포함한 환경을 설정합니다.
-   **코딩 에이전트**: 각 세션마다 점진적인 코드 개선을 수행하고, 다음 세션을 위해 명확한 결과물을 남깁니다.

주요 개선 사항은 다음과 같습니다.

-   **기능 목록 관리**: 초기화 에이전트는 사용자 프롬프트 기반의 상세한 기능 요구사항 목록을 생성하고, 각 기능 상태를 JSON 형식으로 관리하여 에이전트가 작업을 누락하거나 조기에 완료하는 것을 방지합니다.
-   **점진적 진행 및 테스트**: 코딩 에이전트는 한 번에 하나의 기능에 집중하며, git 커밋과 진행 상황 요약을 통해 코드 변경 사항을 명확히 하고 롤백 기능을 활용합니다. 또한, 브라우저 자동화 도구를 활용하여 사람 사용자와 유사한 방식으로 엔드투엔드 테스트를 수행합니다.
-   **환경 설정 및 실행**: 각 코딩 에이전트 세션 시작 시 `pwd` 실행, git 로그 및 진행 파일 확인, 기능 목록 검토 후 가장 우선순위가 높은 미완료 기능을 선택합니다. `init.sh` 스크립트로 개발 서버를 실행하고 기본적인 엔드투엔드 테스트를 수행하여 앱이 정상 상태인지 확인 후 작업을 시작합니다.

이러한 접근 방식은 에이전트가 이전 작업 내용을 파악하고 버그를 수정하는 데 소요되는 시간을 줄여 효율성을 높입니다.
