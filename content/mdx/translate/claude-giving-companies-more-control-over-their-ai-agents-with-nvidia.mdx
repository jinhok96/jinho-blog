NVIDIA는 AI 보안 강화를 위한 오픈 소프트웨어 플랫폼인 [Open Agent Safety Platform](https://nvidianews.nvidia.com/news/open-agent-safety-platform)을 발표했습니다. Anthropic은 NVIDIA와 협력하여 에이전트 스택에 추가적인 보안 및 제어 계층을 통합했습니다.

*   **Claude Managed Agents**: 에이전트가 필요한 인증 정보를 안전하게 보관하여 직접 접근하지 못하도록 합니다.
*   **NVIDIA OpenShell**: 에이전트의 실행 범위와 접근 권한을 제어하는 오픈 소스 소프트웨어입니다.
*   **계층적 보호**: 모델 내부의 보호 기능 외에도, 외부에서 에이전트의 행동을 제어하는 독립적인 보호 계층을 추가하여 보안을 강화합니다.
*   **보안 강화 기능**: Managed Agents는 보안 샌드박싱, 인증, 도구 실행을 제공하며, OpenShell은 에이전트의 모든 행동을 모니터링하고 규칙을 적용합니다.
*   **가용성**: Managed Agents는 즉시 사용 가능하며, OpenShell은 GitHub에서 오픈 소스로 제공됩니다.
