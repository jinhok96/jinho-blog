ABC Legal은 1,100명의 직원이 Claude Enterprise를 활용하여 부서별 업무 자동화를 자체적으로 구축하도록 지원했습니다. 이를 통해 운영 효율성을 높이고 업무 부담을 줄였습니다.

-   **Claude Managed Agents 도입**: 기존에 개별 PC에 분산되어 있던 에이전트를 클라우드 기반의 통합 관리 시스템으로 전환하여 중앙 집중식 관리, 버전 관리, 가시성 확보 및 비용 절감을 실현했습니다.
-   **에이전트를 코드로 취급**: 모든 에이전트를 코드처럼 관리하여 형상 관리 시스템(git)에 저장하고, Pull Request를 통해 변경 사항을 관리하며 코드 리뷰, 롤백, 감사 추적 기능을 확보했습니다.
-   **기술 격차 해소**: 개발자가 아닌 직원들도 Claude Code를 통해 에이전트를 쉽게 구축하고 운영할 수 있도록 지원하여, 전사적인 자동화 도입을 가속화했습니다.
-   **다양한 업무 자동화**: 법률 문서 처리의 각 단계에서 에이전트를 활용하여 코드 리뷰, 증거 기록 관리, 전자 소송 거부 진단, 변호사 섭외, 송금 처리 등 다양한 업무를 자동화했습니다.
-   **AI 피드백 루프 구축**: 수집된 인간의 피드백을 활용하여 에이전트의 성능을 지속적으로 개선하고, 인간과 AI가 협력하여 업무를 수행하는 모델을 구축했습니다.

ABC Legal은 Claude Managed Agents를 통해 모든 직원이 빌더가 되어 업무 자동화를 주도하고, 궁극적으로는 AI가 지원하는 스스로 운영되는 비즈니스를 구축하고자 합니다. 자세한 내용은 원문에서 확인하세요.
