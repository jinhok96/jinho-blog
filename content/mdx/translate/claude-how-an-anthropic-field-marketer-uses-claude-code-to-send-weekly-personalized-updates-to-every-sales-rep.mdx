Anthropic의 필드 마케터가 Claude Code를 활용하여 영업 담당자 개개인에게 맞춤화된 주간 업데이트를 자동화한 사례를 소개합니다. 기존에는 수동으로 자료를 취합하고 슬라이드를 만들어 전달했지만, Claude Code 도입 후 반복적인 업무를 자동화하고 각 영업 담당자의 계정과 관심사에 최적화된 정보를 제공하게 되었습니다.

- **AI 활용의 핵심은 기술적 이해보다 문제 설명 능력입니다.** 기술적 지식이 없어도 Claude Code에게 명확한 목표와 맥락을 설명하면, 제품 관리자처럼 문제를 해결해 나갈 수 있습니다.
- **데이터 연결 및 개인화:** BigQuery와 같은 데이터 소스와 Claude Code를 연결하여 영업 담당자의 지역 정보, CRM 데이터, Slack 채널의 업데이트 내용을 종합적으로 파악하여 개인화된 메시지를 생성합니다.
- **사용자 피드백 기반의 프롬프트 엔지니어링:** 초기 테스트 그룹의 피드백을 적극적으로 반영하여 프롬프트를 개선했습니다. 예를 들어, 존재하지 않는 URL 생성 금지, 이벤트 참석 대상자 불일치 시 제외 등의 규칙을 추가했습니다.
- **반복적인 수동 업무 자동화 및 확장:** 이 시스템은 영업팀뿐만 아니라 비즈니스 개발 담당자, 고객 성공팀, 제휴팀 등으로 확장되었으며, 마케팅 활동에 대한 전반적인 개요도 제공합니다.
