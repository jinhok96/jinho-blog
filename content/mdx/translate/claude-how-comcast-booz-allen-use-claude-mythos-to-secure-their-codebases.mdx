Anthropic은 보안 전문가들이 코드베이스 보안을 강화할 수 있도록 지원하는 Cyber Verification Program (CVP)의 확장 버전을 출시했습니다.

- Claude Mythos 모델은 개별 파일이 아닌, 코드, 설정, 애플리케이션 동작 전반에 걸쳐 문맥을 파악하여 시스템 간 상호작용에서 발생하는 정교한 보안 취약점을 탐지합니다.
- Comcast는 Claude Mythos Preview를 사용하여 2억 5,800만 줄의 코드에서 인증 우회 가능성이 있는 치명적인 취약점을 발견했으며, 이는 개별 구성 요소의 결함이 아닌 여러 시스템 간의 상호작용에서 비롯되었습니다.
- Booz Allen은 Claude Mythos Preview를 통해 단기간에 더 많은 소프트웨어를 검토하고, 여러 작은 취약점이 연결되어 발생하는 익스플로잇 체인을 식별하는 데 활용했습니다.
- Claude Mythos는 코드, 구성, ID, 권한 및 배포 컨텍스트를 연결하여 보안 가설을 생성하고, 수정 초안을 작성하며, 엔지니어가 문제를 신속하게 해결하도록 지원합니다.
