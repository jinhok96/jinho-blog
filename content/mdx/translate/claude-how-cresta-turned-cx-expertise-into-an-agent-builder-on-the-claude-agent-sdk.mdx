Cresta는 고객 경험(CX) 분야의 전문성을 활용하여 'Conductor'라는 새로운 에이전트 빌더를 개발했습니다. Conductor는 복잡한 비즈니스 컨텍스트를 활용하여 프로덕션 준비가 된 에이전트를 구축하도록 돕는 자연어 에이전트 빌더입니다.

- Conductor는 Claude Agent SDK를 활용하여 컨텍스트 수집, 도구 사용, 코드 작성 및 실행 등 오픈형 개발 작업을 지원하는 일반 목적의 프레임워크 역할을 합니다.
- Cresta는 Conductor가 초기 에이전트 배포 시간을 약 절반으로 단축했다고 보고합니다.
- Conductor는 CX 에이전트 개발에 대한 모범 사례를 기반으로 한 메타 에이전트로, 개발 과정을 통해 얻은 패턴, 워크플로우 및 전문 지식을 재사용 가능한 스킬로 캡처하여 향후 개발을 더 빠르고 일관되게 만듭니다.
- Cresta는 Conductor를 통해 고객이 직접 에이전트를 구축할 수 있는 환경을 제공하며, 이는 내부 팀 지원을 위한 초기 버전을 제품화한 것입니다.
- Conductor는 에이전트 구축 작업(새 에이전트 구축, 테스트 케이스 작성, 기존 에이전트 변경, 근본 원인 분석)을 통해 평가되며, 결과물, 실행 경로, 품질, 리소스 사용량 등을 종합적으로 고려합니다.
