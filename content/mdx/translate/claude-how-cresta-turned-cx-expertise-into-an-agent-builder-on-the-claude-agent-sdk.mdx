Cresta는 풍부한 고객 경험(CX) AI 에이전트 구축 전문성을 바탕으로, 개발자들이 직접 다른 에이전트를 구축하고 개선할 수 있도록 돕는 'Conductor'라는 새로운 에이전트 빌더를 개발했습니다.

*   **Conductor**: 복잡한 비즈니스 컨텍스트를 프로덕션 수준의 에이전트로 전환할 수 있도록 지원하는 자연어 에이전트 빌더입니다. 사용자가 구축하고자 하는 바를 설명하면, Conductor가 청사진부터 구현, 평가, 최적화까지 전 과정을 안내합니다.
*   **Claude Agent SDK 활용**: Cresta는 Claude Agent SDK를 일반 목적의 프레임워크로 사용하여 컨텍스트 수집, 도구 사용, 코드 작성 및 실행, 결과 기반 적응 기능을 구현했습니다. 이를 통해 내부적으로 사용하던 에이전트 개발 시스템을 고객이 직접 사용할 수 있는 제품으로 발전시켰습니다.
*   **CX 전문성과 결합**: Conductor는 Cresta의 심층적인 대화 인텔리전스, CX 전문성, 평가 방법론, 런타임 기능을 Claude Agent SDK와 통합하여, 초기 에이전트 배포 시간을 약 절반으로 단축시켰다고 보고되었습니다.
*   **셀프 개선 메타 에이전트**: Conductor는 구축 및 개선되는 에이전트를 통해 학습된 패턴, 워크플로우, 전문가 판단을 재사용 가능한 메모리 아티팩트로 캡처하여 팀원들과 공유할 수 있습니다. 이는 지식 플라이휠을 형성하여 향후 개발을 더 빠르고 일관성 있게 만듭니다.
*   **결정적인 부분과 유연한 부분 구분**: Conductor는 에이전트 구축 시, 모든 경우에 완벽하게 작동해야 하는 핵심적인 비즈니스 워크플로우를 식별하고 강화하는 동시에, 전반적인 경험 개선을 위해 유연하게 조정할 수 있는 기능을 제공합니다.
