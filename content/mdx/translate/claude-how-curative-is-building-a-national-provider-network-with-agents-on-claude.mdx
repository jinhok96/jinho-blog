Curative는 Claude Platform과 Claude Code를 활용하여 전국 규모의 의료 서비스 제공업체 네트워크를 구축했습니다. 이를 통해 공급업체 계약 체결 프로세스를 획기적으로 단축하고 효율성을 높였습니다.

-   **Gwen**: 공급업체 계약 전 과정을 자동화하는 핵심 에이전트로, 초기 접촉부터 계약 서명까지 처리합니다.
-   **AI 기반 계약 속도 향상**: Gwen과 보조 에이전트 덕분에 공급업체 계약 체결 속도가 이전 대비 약 50배 빨라졌습니다.
-   **다양한 Claude 모델 활용**: Gwen은 Claude Opus로, 계약 조건 검토는 Sonnet으로, 메시지 감사는 Haiku로 처리하여 각 작업에 최적화된 모델을 사용합니다.
-   **코드 생성 및 시스템 재구축**: Claude Code를 활용하여 맞춤형 보험금 청구, 사전 승인, 재무 시스템을 재구축했으며, 이는 엔지니어링 시간을 크게 절약했습니다.
-   **향후 계획**: 케어 내비게이션 분야로 에이전트 활용을 확장하고, 공급업체가 계약 협상에 에이전트를 활용하도록 지원할 예정입니다.
