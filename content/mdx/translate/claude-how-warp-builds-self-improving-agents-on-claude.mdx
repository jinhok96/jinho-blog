Warp는 Claude Platform을 기반으로 자체 개선 루프를 갖춘 에이전트를 구축했습니다. 이 방식은 에이전트의 성능을 지속적으로 향상시키는 데 중점을 둡니다.

*   **자체 개선 루프**: 에이전트의 기능 지식을 담은 '내부/기본 스킬'과 사용자 피드백을 기반으로 기본 스킬을 개선하는 '외부/개선 스킬'로 구성됩니다.
*   **피드백 활용**: 사용자 피드백은 에이전트의 출력을 평가하고 개선할 내용을 결정하는 데 사용됩니다. 상세하고 명확한 피드백이 중요합니다.
*   **스킬 기반 아키텍처**: 스킬은 파일 기반으로 관리되어 코드 리뷰 및 병합 과정을 통해 에이전트의 지식이 점진적으로 업데이트됩니다.
*   **효율적인 피드백 수집**: 사용자가 작업하는 환경(예: PR 코멘트)에서 피드백을 쉽게 수집하고, 자동화된 프로세스를 통해 피드백의 마찰을 줄입니다.
