Anthropic은 2주간의 스프린트 동안 claude.ai와 Claude 데스크톱 앱의 핵심 사용자 경험을 약 3배 더 빠르게 만드는 데 성공했습니다. 사용자 활동의 95%를 차지하는 네 가지 주요 여정에 집중했으며, 이를 통해fresh load 시 typeable 페이지 로딩 시간을 3.1초에서 0.55초로, Claude Code 세션 시작 시간을 0.8초에서 0.3초로, Claude Cowork 클라우드 세션 로딩 시간을 2.6초에서 0.73초로 단축했습니다.

*   **AI 기반 성능 개선:** Claude AI 모델을 사용하여 병목 현상을 식별하고, 벤치마크를 구축하며, 개선 사항을 적용하고, 배포를 모니터링하는 등 전 과정에 걸쳐 AI의 도움을 받았습니다.
*   **핵심 사용자 여정 최적화:** 앱 실행, 대화 시작, 기존 대화 로딩, 메시지 전송 등 사용자 활동의 대부분을 차지하는 네 가지 핵심 여정에 집중하여 성능을 개선했습니다.
*   **측정 가능한 성능 향상:** JavaScript 명령어 수, React 커밋 수, V8 함수 호출 수, 레이아웃 계산 수, DOM 변경 수 등 다양한 지표를 실험실 환경에서 측정하고 이를 사용자 경험 개선과 연결했습니다.
*   **안전하고 효율적인 배포:** 모든 변경 사항은 자동 검토, 단위 테스트, 기능 플래그를 통해 안전하게 배포되었으며, 200개에 가까운 기능 플래그가 도입되었지만 대부분 2주 안에 정리되었습니다.
*   **지속적인 성능 개선 루프:** Slack 채널 내에서 발생한 문제를 기반으로 Claude가 벤치마크를 만들고, PR을 제출하며, 실제 데이터를 통해 성능을 검증하고, 벤치마크를 조정하는 반복적인 과정을 통해 지속적으로 성능을 향상시켰습니다.
