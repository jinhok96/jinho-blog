Claude Ship은 GitHub에서 풀 리퀘스트(PR)를 자동으로 검토, 수정 및 병합 승인하는 새로운 AI 도구입니다.

-   **Claude Ship의 핵심 기능:**
    -   **Code Review (일반 출시):** PR에 대한 심층 분석을 제공하며, 검토 레벨(Quick, Standard, Deep)을 선택할 수 있습니다.
    -   **PR Steward (베타):** CI 오류, 병합 충돌, 리뷰 피드백 등을 자동으로 해결하고, 개발자가 `@claude` 명령으로 조작할 수 있습니다.
    -   **Claude Approvals (베타):** 팀이 정의한 정책에 따라 PR을 자동으로 승인하거나 인간의 검토를 요청하며, `CODEOWNERS` 파일보다 스마트하게 작동합니다.

-   **시작 방법:**
    -   **개발자:** Claude Code에서 `/ship` 명령을 사용하여 PR을 제출하고 자동화 프로세스를 경험할 수 있습니다.
    -   **관리자/리더:** 각 저장소별로 Claude Ship 설정을 구성하고, PR Steward를 활성화하며, `Claude Approvals` 정책 파일을 설정하여 자동화 수준을 제어할 수 있습니다.

-   **Claude Ship 작동 방식:**
    AI는 PR 검토, 코드 수정, CI/CD 파이프라인 관리, 그리고 정의된 정책에 따른 승인 결정을 자동으로 수행합니다.

Claude Ship은 Claude Team 및 Enterprise 요금제를 통해 GitHub 저장소에서 사용할 수 있습니다. 자세한 내용은 원문에서 확인하세요.
