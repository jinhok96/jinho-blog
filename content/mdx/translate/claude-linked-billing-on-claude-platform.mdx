Claude 플랫폼에서 '연결된 결제' 기능이 베타 출시되었습니다. 이 기능을 통해 타사 플랫폼은 고객이 Claude API 키를 공유하지 않고도 API 사용 요금을 고객에게 직접 청구할 수 있습니다.

-   **보안 강화:** API 키 공유 대신 고객의 Claude Platform 조직을 연결하므로, 타사 플랫폼은 고객의 API 키를 저장, 암호화 또는 관리할 필요가 없어 보안 위험이 줄어듭니다.
-   **플랫폼의 간편한 Claude 제공:** 타사 플랫폼은 자체 빌링 시스템을 구축할 필요 없이 Claude API 사용량을 고객에게 직접 청구할 수 있습니다. 이를 통해 더 빠르게 서비스를 출시하고, 고객별 사용량을 파악하며, 결제 주체를 선택할 수 있습니다.
-   **고객의 가시성 및 제어 강화:** 고객은 단 한 번의 승인으로 여러 플랫폼에 조직을 연결하고, 각 플랫폼별로 월별 사용량 한도를 설정하며, API 사용 내역을 쉽게 확인할 수 있습니다. 또한 원할 때 언제든지 연결을 해제할 수 있습니다.
-   **플랫폼별 정책 미적용:** 연결된 결제를 통해 실행되는 요청은 플랫폼의 조직 내에서 처리되므로, 고객 조직의 IP 허용 목록, 암호화 키, 데이터 보존과 같은 설정은 적용되지 않습니다.
