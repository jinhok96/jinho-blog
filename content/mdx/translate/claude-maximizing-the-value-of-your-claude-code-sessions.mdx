Claude Code 세션의 효율성을 높여 비용을 절감하고 더 나은 결과를 얻는 방법에 대한 안내입니다. Claude Code는 사용 방식에 따라 작업 완료 비용이 달라질 수 있습니다.

-   **`/clear` 명령어를 사용하여 작업 간의 불필요한 컨텍스트를 제거합니다.** 이렇게 하면 이전 작업의 관련 없는 정보가 모델에 전달되는 것을 방지하여 토큰 사용량을 줄일 수 있습니다.
-   **세션 시작 전에 모델과 노력 수준을 설정합니다.** 대화 중간에 변경하면 프롬프트 캐시가 손상되어 토큰 비용이 증가할 수 있습니다.
-   **파일 이름을 직접 입력하는 대신 `@-mention`으로 참조합니다.** 파일을 메시지에 직접 첨부하여 Claude가 파일을 찾아야 하는 검색 또는 읽기 작업을 줄여줍니다.
-   **출력이 많은 명령어에는 조용히 실행 옵션을 추가하거나 하위 에이전트에서 실행합니다.** 명령어 출력도 파일처럼 대화에 추가되며 세션 끝까지 유지됩니다.
-   **새 세션에서 `/context`를 한 번 실행하여 로드된 내용을 확인합니다.** 불필요한 항목을 제거하여 컨텍스트를 최적화할 수 있습니다.
-   **잠시 자리를 비울 때는 `/compact`를 실행합니다.** 프롬프트 캐시는 1시간 후에 만료되므로, 캐시된 상태에서 대화를 요약하는 것이 훨씬 저렴합니다.
