Anthropic은 Python으로 작성된 Messages API를 Rust로 성공적으로 마이그레이션했습니다. 이 API는 고객 및 자체 서비스에서 Claude에 접근하는 주요 경로로, API 트래픽이 급증하면서 CPU 사용량 절감이 필요했습니다.

*   **Rust 마이그레이션 목표:** Python API 대비 CPU 사용량을 약 70% 절감하고, 최초 토큰 생성 시간을 약 20% 단축하는 것을 목표로 했습니다.
*   **검증 방법론:** 기존 Python API를 '오라클'처럼 사용하여 Rust API와의 동등성을 검증하는 새로운 방식을 도입했습니다. 이를 통해 실제 운영 트래픽에서 Rust 버전을 테스트하고 차이점을 발견하여 자동으로 수정하는 시스템을 구축했습니다.
*   **핵심 검증 기법:**
    *   **체크포인팅(Checkpointing):** API 처리 과정의 각 단계를 비교하여 차이가 발생하는 지점을 식별했습니다.
    *   **지문(Fingerprint):** 각 차이점의 시작 위치와 길이 정보를 기록하여 특정 버그를 구분하고 그룹화했습니다.
*   **자율 수정 시스템:** 발견된 차이점을 기록하고, 이 정보를 바탕으로 Claude 에이전트가 수정 작업을 수행하며, 내부 및 외부 루프를 통해 수정 사항을 검증하는 자동화된 워크플로우를 구축했습니다.
