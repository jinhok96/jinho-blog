Claude는 개발자뿐 아니라 모든 팀이 마법 같은 경험을 할 수 있도록 기능을 확장하고 있습니다. 새로운 **Claude Sheets**, **Claude Whiteboards**, **Claude Data**와 같은 새로운 아티팩트(artifact) 유형을 선보이며, 사용자가 주로 이용하는 앱과의 연동성을 강화한 **Interactive Connectors**를 업그레이드했습니다. 곧 **Claude Meetings** 기능도 출시될 예정입니다.

Claude는 [Model Context Protocol (MCP)](https://www.anthropic.com/news/model-context-protocol) 기반의 커넥터를 통해 이메일, 앱, 드라이브 등에 흩어진 정보를 통합하여 활용합니다. 현재 Claude Marketplace에는 9,000개 이상의 커넥터와 플러그인이 등록되어 있습니다.

**Interactive Connectors**는 Adobe, Atlassian 등 다양한 앱을 Claude 내부에 직접 임베드하여 탭 전환 없이 작업할 수 있게 지원합니다. Salesforce, NetSuite, Workday 등과의 연동을 통해 영업, 재무, HR 팀은 각자의 업무를 Claude에서 직접 처리할 수 있습니다.

Claude는 이제 팀과 함께 스프레드시트, 화이트보드, 대시보드까지 구축할 수 있습니다. 기존의 문서, 슬라이드 덱, 디자인 생성 기능과 [Claude Motion](https://support.claude.com/en/articles/17454997-get-started-with-claude-motion) (베타)을 통한 짧은 애니메이션 제작 기능과 연계됩니다.

*   **새로운 아티팩트 유형**:
    *   **Claude Sheets**: 팀과 Claude가 협업하여 스프레드시트를 만들고 데이터를 정리하며, 여러 탭을 넘나들며 수식을 생성하고 편집할 수 있습니다.
    *   **Claude Whiteboards**: 팀이 아이디어를 레이아웃하고 구성할 수 있는 디지털 화이트보드 기능을 제공하며, Claude가 회의 내용을 요약해 줍니다.
    *   **Claude Data**: Snowflake, Salesforce 등과 연결하여 데이터 팀이 인증한 정의를 사용해 대시보드, 데이터 스토리, 짧은 영상 등을 생성합니다.

또한, 팀의 업무 방식에 맞춰 계정 추적기, 일일 브리핑, 프로젝트 상태 보드 등 맞춤형 아티팩트 생성이 가능하며, Claude는 동일한 컨텍스트를 유지하여 아이디어를 여러 아티팩트에 걸쳐 자연스럽게 연계할 수 있습니다.

곧 출시될 **Claude Meetings**는 Claude를 통화에 참여시켜 회의 내용을 기록하고 관련 문서를 업데이트하는 기능을 제공합니다.

내부적으로는 법무팀이 Claude를 활용해 사내 플레이북 기반의 Slack 법률 검토 도구를 개발했으며, 마케팅 검토 시간을 획기적으로 단축했습니다. 재무팀은 임원을 위한 비즈니스 업데이트 문서를 Claude와 함께 상호작용 가능한 페이지로 전환했습니다.

기업 환경을 위해 Claude는 액세스와 작업에 대한 감독을 강화했습니다. **Claude auto-connect** (베타) 기능을 통해 Notion, Atlassian, Dropbox와 같은 앱 연결이 간소화되며, 사용자의 기존 권한 내에서 작동합니다.

*   기업의 데이터는 전송 중 및 저장 시 암호화됩니다.
*   Enterprise 플랜에서는 감사 로그와 Compliance API를 통해 Claude 사용 현황을 파악할 수 있습니다.
*   새로운 Claude 환경에서는 각 클라우드 세션이 독립적인 가상 머신에서 실행되며, 커넥터 자격 증명은 외부에 안전하게 보관됩니다.

Claude는 연결된 도구를 통해 팀의 작업을 이해하고, 필요한 형식으로 아이디어를 구현하며, 관리자가 설정한 제어 내에서 작동하여 사용자가 중요한 목표에 집중하고 진척시킬 수 있도록 지원합니다.
