Claude 프로젝트는 이제 작업을 여러 세션으로 나누고 수동으로 결과를 통합하던 방식에서 벗어나, 사용자가 목표를 설정하면 Claude가 직접 작업을 구성하고 위임하며 조정합니다.

*   **자동화된 작업 관리:** Claude는 요청 범위를 설정하고, 작업을 분담하며, 병렬 스레드를 조정하고, 결과물을 검토한 후 최종 결과물을 통합합니다. 사용자는 진행 상황을 실시간으로 제어할 수 있으며, Claude는 사용자가 자리를 비운 후에도 작업을 계속합니다.
*   **새로운 프로젝트 베타 출시:** 선택된 Claude Pro 및 Max 구독자에게 클라우드 세션을 사용하는 새로운 프로젝트 기능이 베타로 제공됩니다.
*   **스레드를 통한 작업 실행:** 각 프로젝트는 작업을 수행하는 스레드와 이를 지시하는 코디네이터로 구성됩니다. 사용자는 메인 프로젝트 채팅 또는 개별 스레드에서 진행 상황을 모니터링하고 안내할 수 있습니다.
*   **시간이 지남에 따른 컨텍스트 구축:** 프로젝트는 장기적이거나 에이전트 기반 워크플로우를 위해 설계되었습니다. Claude는 시간이 지남에 따라 프로젝트 세부 정보를 학습하고 이를 작업에 적용하며, 공유 메모리에 저장하여 복잡한 프롬프트 엔지니어링의 필요성을 줄입니다.
*   **향후 업데이트:** 클라우드에서 실행되는 스레드는 곧 로컬 환경에서도 실행될 예정이며, 사용량 제한을 더 잘 관리하고 조정 및 작업 스레드에 사용되는 모델과 노력 수준을 선택할 수 있는 기능이 제공됩니다.
