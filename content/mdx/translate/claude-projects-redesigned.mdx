Claude 프로젝트의 새로운 기능은 기존의 분산된 작업 관리를 혁신합니다. 이제 사용자는 해야 할 일을 설명하기만 하면 Claude가 프로젝트의 모든 작업을 관리합니다.

-   **자동화된 작업 관리:** Claude는 요청 범위를 설정하고, 작업을 위임하며, 병렬 스레드를 조정하고, 결과물을 검토한 후 최종 결과물을 종합합니다. 사용자는 진행 상황을 실시간으로 제어할 수 있으며, 컴퓨터에서 벗어나 있을 때도 작업은 계속 진행됩니다.
-   **지능형 스레드 운영:** 프로젝트에는 작업을 수행하는 여러 '스레드'가 있으며, Claude 코디네이터가 이들을 관리합니다. 사용자는 목표와 컨텍스트를 선택하면 Claude가 즉시 시작할 수 있는 작업을 제안합니다. 각 스레드는 Claude Code 클라우드 세션으로 작동하며, 풀 리퀘스트를 열고 테스트를 실행하는 등의 작업을 수행합니다.
-   **지속적인 컨텍스트 학습:** 프로젝트는 장기적이거나 에이전트형 워크플로우를 위해 설계되었습니다. Claude는 시간이 지남에 따라 프로젝트 세부 정보를 학습하고 공유 메모리를 통해 이를 활용하여 복잡한 프롬프트 엔지니어링의 필요성을 줄입니다.
-   **향상된 자료 관리:** 프로젝트에 라이브러리가 추가되어 사용자가 추가한 파일과 Claude가 생성한 결과물을 쉽게 찾고 과거 작업에 기반한 새로운 작업을 용이하게 합니다.

이 업데이트된 프로젝트 기능은 클라우드 세션을 사용하는 Claude Pro 및 Max 구독자에게 베타로 제공됩니다.
