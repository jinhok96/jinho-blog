Anthropic은 Claude AI의 혁신적인 코드 생성 능력 덕분에 이전에는 경험하지 못했던 속도와 규모로 소프트웨어를 구축하고 연구를 진행하고 있습니다. 이러한 발전으로 인해 하루 평균 2,500건에서 30,000건 이상의 코드 변경이 병합될 정도로 소스 컨트롤, 빌드, CI와 같은 개발 인프라에 병목 현상이 발생했습니다.

이 문제를 해결하기 위해 Anthropic은 5개월 만에 자체 소스 컨트롤 시스템인 Scion을 구축하고 기존의 monorepo를 git에서 완전히 마이그레이션했습니다. 또한 이 기간 동안 코드 검토 인터페이스(Antique), 코드 검색, IAM 시스템, 대규모 코드 관리 방안 등을 함께 개발했습니다.

Scion은 다음과 같은 핵심 원칙을 기반으로 설계되었습니다.

*   **클라이언트 항상 온라인:** 에이전트와 작업은 항상 온라인 상태임을 가정하고, 서버에 연결하여 필요한 데이터를 가져옵니다.
*   **클라이언트-서버 비대칭:** Scion 서버는 저장소 관련 정보, 커밋 생성, 병합 등을 담당하며, 클라이언트는 최소한의 로컬 캐시와 작업 복사본만 유지합니다.
*   **확장 가능한 통합 소스 컨트롤 서비스:** 모든 소스 컨트롤 쿼리가 API로 제공되어, 많은 작업이 로컬 저장소 없이도 소스 컨트롤 정보를 활용할 수 있습니다.
*   **수평 확장성:** 저장소 데이터가 분산되어 있으며 모든 구성 요소가 독립적으로 확장 가능합니다.
*   **저렴하고 즉각적인 커밋:** 모든 커밋, 리베이스, 병합은 서버에서 이루어지며, 변경량에 따라 비용이 확장되어 속도 저하를 방지합니다.
*   **선택적이고 희소한 작업 복사본:** 필요한 부분만 가져오는 스파스 체크아웃과 필요할 때 파일을 가져오는 가상화된 체크아웃을 지원하여 효율성을 높입니다.

Scion은 변경 사항을 "changeset"이라는 쓰기 전 로그 항목으로 저장하며, 각 changeset은 변경된 파일 목록과 압축된 파일 콘텐츠에 대한 포인터를 포함합니다. 이를 통해 높은 처리량을 지원하며, 파일 블레임 및 경로 기록 등 다양한 파생 데이터 구조를 생성하여 Git의 복잡한 내부 메커니즘 없이도 효율적인 쿼리가 가능합니다.

Anthropic은 Scion과 Antique를 7명의 팀이 5개월 만에 개발 및 마이그레이션을 완료했습니다. 이 과정에서 Claude AI는 코드 작성뿐만 아니라, 엔지니어들이 시스템 전반의 복잡한 상호작용과 설계 트레이드오프에 집중할 수 있도록 도왔습니다. 또한, Claude AI는 Scion의 테스트 및 방어 코드베이스를 강화하고, 최적화 및 새로운 보안 기능 개발에 기여했습니다.

이러한 경험을 통해 Anthropic은 AI 에이전트 시대의 소프트웨어 개발은 더욱 빠르고 민첩해질 것이며, 엔지니어의 역할은 코드를 작성하는 것에서 시스템의 의도와 설계 결정을 내리는 것으로 변화할 것이라고 예측합니다.
