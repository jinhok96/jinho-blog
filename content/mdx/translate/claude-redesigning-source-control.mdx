Anthropic은 AI 코드 생성 능력 덕분에 개발 속도가 기하급수적으로 증가하여 기존의 인간 규모 개발 인프라가 병목 현상을 일으키고 있습니다. 특히 하루 30,000건 이상의 코드 변경 사항 병합을 지원하기 위해 자체 소스 컨트롤 시스템 'Scion'을 개발하고 5개월 만에 git에서 마이그레이션을 완료했습니다.

Scion은 다음과 같은 원칙을 기반으로 설계되었습니다.

-   **항상 온라인 상태인 클라이언트:** 거의 모든 클라이언트가 에이전트이므로 서버는 항상 접근 가능하며 클라이언트는 필요할 때 데이터를 가져옵니다.
-   **클라이언트-서버 비대칭성:** 서버가 히스토리, 커밋 생성, 병합 등을 담당하고 클라이언트는 제한된 로컬 캐시와 작업 복사본을 관리합니다.
-   **수평적 확장성:** 저장소 데이터는 분산되며 모든 컴포넌트는 독립적으로 확장 가능합니다.
-   **저렴하고 증분적인 잠금 없는 커밋:** 모든 커밋, 리베이스, 병합은 서버에서 이루어지며, 변경 사항의 크기에 따라 확장됩니다.
-   **선택적이고 희소한 작업 복사본:** 작업 복사본은 필요에 따라 파일을 동적으로 로드하는 방식으로 작동하여 불필요한 데이터 로드를 방지합니다.

Scion은 "changeset"라는 쓰기 선행 로그 항목을 작업 단위로 사용하며, 각 changeset은 변경된 파일 목록과 내용 기반 주소 지정된 압축 파일 콘텐츠를 저장합니다. 이를 통해 높은 처리량의 changeset 수용이 가능하며, 추가적인 "유도 데이터" 구조를 통해 파일 blame 및 경로 히스토리와 같은 쿼리에 대한 빠른 응답을 제공합니다. Scion 서버는 수평적으로 확장 가능하며, 클라이언트는 효율적이고 재개 가능한 프로토콜을 통해 필요한 객체만 요청합니다.

Scion과 자체 코드 리뷰 도구인 Antique 구축을 통해 7명의 소규모 팀이 5개월 만에 복잡한 시스템을 개발하고 마이그레이션하는 속도 향상을 경험했습니다. 이를 통해 AI가 코드를 작성하는 역할과 엔지니어의 시스템 설계 및 의도 파악 역할이 분담되는 새로운 개발 방식을 확인했습니다. Scion은 또한 방대한 모노레포 보안을 위한 기반을 마련했으며, CDNs와 유사한 계층화된 캐싱 구조를 통해 운영 효율성을 크게 향상시켰습니다.
