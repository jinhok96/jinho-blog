Claude Code 세션을 조직의 자체 인프라에서 실행할 수 있는 새로운 베타 기능이 출시되었습니다. 이 기능은 웹, 모바일, 데스크톱 등 어떤 환경에서든 세션을 시작하면 사용자 네트워크 내부에서 실행되므로 내부 서비스, 툴체인 및 보안 제어 기능에 더 가깝게 접근할 수 있습니다.

주요 이점은 다음과 같습니다.

*   **네트워크 접근성:** 세션이 조직의 네트워크 내에서 실행되어 내부 서비스, 데이터베이스 등에 안전하게 접근할 수 있습니다.
*   **맞춤 설정:** 필요한 컴파일러, SDK, 내부 CLIs를 미리 설치하여 세션이 즉시 개발 준비 상태가 되도록 할 수 있습니다.
*   **규정 준수:** 소스 코드와 빌드 아티팩트가 조직이 통제하는 인프라에 유지됩니다.

데이터는 저장 프로비저닝한 인프라에 그대로 유지되며, 프롬프트, 응답, 도구 결과 등을 포함한 대화 내용은 추론을 위해 Anthropic으로 전송됩니다.

이 기능은 [runners](https://code.claude.com/docs/en/self-hosted-environments#key-concepts)라는 구성 요소 세트를 배포하여 작동합니다. Runners는 고정 모드 또는 주문형 모드로 실행될 수 있으며, 각 세션은 자체 체크아웃에서 실행되어 작업이 격리됩니다.

이 기능은 Claude Team 및 Enterprise 플랜 고객에게 베타 버전으로 제공됩니다. 자세한 내용은 [documentation](https://code.claude.com/docs/en/self-hosted-environments)에서 확인하세요.
