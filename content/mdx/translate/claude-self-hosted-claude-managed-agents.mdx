Claude 관리형 에이전트의 자체 호스팅(Self-hosted) 버전이 현재 비공개 베타로 제공됩니다. 이를 통해 개발자는 회사의 코드 및 내부 시스템에서 직접 작동하는 에이전트를 구축하고, 해당 에이전트를 자체 환경에서 실행할 수 있습니다.

*   **에이전트 제어부 자체 호스팅:** 이전에는 Anthropic이 호스팅하는 클라우드 서비스로 제공되었던 Claude 관리형 에이전트의 모든 구성 요소(하네스, 샌드박스, 자격 증명 관리, 세션 기록)를 이제 자체 클라우드 또는 온프레미스 환경에서 운영할 수 있습니다.
*   **보안 강화 설계:** 에이전트 보안을 위해 '뇌(하네스)'와 '손(샌드박스)' 분리, 샌드박스 외부의 자격 증명 관리, 제한 가능한 네트워크 액세스, 상세한 세션 기록 등 네 가지 원칙을 기반으로 설계되었습니다.
*   **자체 보안 도구 연동:** 자체 호스팅 샌드박스에서는 자체 방화벽 설정을 통해 네트워크 접근을 제한할 수 있으며, 자격 증명은 자체 시크릿 관리자에 저장하고 OpenTelemetry를 통해 감사 추적을 관리할 수 있습니다.
*   **동일한 핵심 API 사용:** 자체 호스팅 환경에서도 기존 클라우드 기반 서비스와 동일한 핵심 API를 사용하여 에이전트를 개발할 수 있습니다.
