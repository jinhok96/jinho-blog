Anthropic은 Claude Tag를 사용하여 Slack에서 데이터 분석에 대한 즉각적인 질문에 응답하는 방식을 공유합니다.

- **스킬 파일의 지속적인 업데이트:** 데이터 모델의 변화를 반영하여 Claude Tag의 스킬 파일을 항상 최신 상태로 유지하는 것이 핵심입니다.
- **분석 스킬 제공:** 단순한 데이터 조회뿐만 아니라 예측, 코호트 분석, 퍼널 분석, 시각화, 분석적 글쓰기와 같은 분석가의 작업 방식을 Claude Tag에 학습시킵니다.
- **비즈니스 맥락 연결:** 데이터 웨어하우스뿐만 아니라 Slack 스레드, 인시던트 트래커, 릴리스 노트 등 내부 지식 인덱스와 연동하여 질문의 맥락을 파악합니다.
- **세심한 권한 관리:** Claude Tag 서비스 계정은 관리되는 데이터로만 접근을 제한하고, PII는 열 수준에서 분류하여 접근을 차단하며, 채널 멤버십을 권한으로 간주합니다.
- **모든 답변 계측:** 모든 질문과 답변에 대한 로그를 기록하고, 채택률과 정확성을 추적하여 서비스 개선에 활용합니다.
