Anthropic은 Claude Tag를 Slack에 성공적으로 배포하여 전 직원이 데이터 분석가와 동일한 거버넌스된 정의를 기반으로 데이터 관련 질문에 답할 수 있도록 합니다. 이 글은 Slack에 데이터 분석 에이전트를 배포하는 데 있어 핵심적인 5가지 학습 내용을 공유합니다.

- **스킬 파일의 최신성 유지**: 데이터 모델 변경 사항을 신속하게 스킬 파일에 반영하여 Claude가 최신 정보를 바탕으로 정확한 답변을 제공하도록 합니다. Claude Tag 런타임은 대화 시점에 스킬 디렉토리를 다시 읽어 최신성을 보장합니다.
- **데이터 쿼리 능력 이상의 스킬 제공**: 단순히 데이터를 찾는 것을 넘어 예측, 코호트 분석, 퍼널 분석, 차트 작성, 분석적 글쓰기 등 분석가의 작업 방식을 이해하는 추가적인 분석 및 런북 스킬을 에이전트에 부여합니다.
- **비즈니스 컨텍스트 연결**: 데이터 웨어하우스뿐만 아니라 Slack 스레드, 인시던트 트래커, 릴리스 노트, 문서 등을 포함하는 내부 지식 인덱스와 Claude Tag를 연결하여 데이터 변경에 대한 심층적인 컨텍스트를 제공합니다.
- **신중한 서비스 계정 권한 설정**: Claude Tag는 서비스 계정으로 데이터 웨어하우스에 접근하므로, 서비스 계정을 거버넌스된 데이터로만 제한하고, PII를 식별 및 차단하며, Slack 채널 멤버십을 통한 접근 권한 부여를 명확히 관리합니다.
- **모든 답변에 대한 계측**: 모든 Claude Tag 질의에 대해 로깅을 수행하여 에이전트의 채택률과 정확성을 추적하고, 데이터 품질 경고를 답변에 포함하여 사용자가 오해 없이 데이터를 해석하도록 돕습니다.
