Claude가 MCP 서버와의 통합을 강화하여 다음과 같은 새로운 기능을 제공합니다.

- **MCP 서버의 스킬(Skills over MCP) 제공**: 서버는 도구와 함께 스킬을 게시하여 Claude가 더 길고 복잡한 작업을 수행할 수 있도록 지원합니다. 스킬은 필요할 때만 로드되며, 도구와 함께 업데이트되어 별도 설치가 필요 없습니다. Shopify, HubSpot, Atlassian 등 다양한 파트너들이 이를 활용하고 있습니다.

- **장기 실행 및 상호작용 작업 지원**:
    - **Tasks**: 서버에서 시간이 오래 걸리는 작업을 백그라운드에서 실행하고, Claude는 결과가 준비되면 이를 가져와 계속 작업을 진행할 수 있습니다. ZoomInfo는 이를 통해 더 심층적인 계정 및 연락처 조사를 수행합니다.
    - **Elicitation**: 작업 중간에 사용자에게 폼이나 링크를 통해 입력을 요청하고, 사용자 입력 후 작업을 이어갈 수 있습니다. Supabase, Railway, GitHub 등이 이 기능을 활용합니다.

- **파일 업로드(File Uploads) 기능 도입**: Claude는 PDF, 스프레드시트, 이미지 등 파일을 텍스트가 아닌 파일 형태로 MCP 서버에 직접 전달할 수 있게 됩니다. 이 기능은 곧 출시될 예정입니다.

이러한 업데이트는 개방형 MCP 스펙 및 확장 기능의 일부로, Claude뿐만 아니라 호환되는 다른 클라이언트에서도 작동합니다. 또한, MCP는 더 높은 토큰 효율성, 확장성, 간소화된 인증, 향상된 상호작용성을 제공하도록 개선되었습니다.
