Claude 5세대 모델 출시와 함께 컨텍스트 엔지니어링 방식에 중요한 변화가 생겼습니다. 이전에는 Claude에게 명확한 규칙과 예시를 제공하는 것이 중요했지만, 이제는 Claude의 판단력을 신뢰하고 인터페이스 설계를 통해 상호작용을 개선합니다.

-   **명령에서 판단으로 전환:** Claude에게 명확한 제약 대신, 코드의 맥락에 맞춰 주석 밀도, 명명 규칙, 관용구를 일치시키도록 안내합니다.
-   **예시에서 인터페이스 설계로:** 명시적인 예시 제공 대신, Claude가 도구를 효과적으로 사용할 수 있도록 매개변수를 표현력 있게 설계하는 데 집중합니다.
-   **일괄 처리에서 점진적 공개로:** 필요한 컨텍스트만 적시에 로드하는 점진적 공개 방식을 활용하여, 복잡한 정보는 별도의 스킬이나 파일로 분리하여 관리합니다.
-   **반복 설명에서 간단한 도구 설명으로:** 시스템 프롬프트에 도구 사용법을 반복적으로 명시하는 대신, 도구 설명 자체에 명확한 지침을 포함합니다.
-   **수동 메모에서 자동 메모로:** 사용자가 직접 Claude의 메모를 관리하는 대신, Claude가 관련성 높은 정보를 자동으로 저장하도록 개선되었습니다.
