Claude Enterprise에서 협업(Cowork)과 채팅 기능이 통합되어 이제 단일 Claude 경험으로 모든 업무를 처리할 수 있습니다.

*   **하나의 Claude로 모든 작업 수행**: 팀원들은 더 이상 업무 시작 전 채팅과 협업을 구분할 필요가 없습니다. 단순 질문은 즉시 답변받고, 코드 실행이나 파일 작업이 필요한 경우 Claude가 클라우드에서 작업을 진행하고 결과를 반환합니다. 웹, 데스크톱, 모바일 어디서든 이전 대화 내용을 그대로 이어서 작업할 수 있습니다.
*   **강화된 보안 유지**: 기존 Claude 채팅에서 사용하던 SSO, Compliance API 등 엔터프라이즈 수준의 보안 기능이 그대로 유지됩니다. Anthropic은 기본적으로 데이터 전송 및 저장 시 암호화를 적용하며, 모델 학습에 데이터를 사용하지 않습니다.
*   **비용 효율적인 모델 및 관리 기능**: Claude Enterprise는 사용량 기반 과금 방식을 유지하며, 새로운 Claude 모델(Opus 5.5, Sonnet 5.5)은 이전 모델 대비 비용 효율성이 향상되었습니다. 또한, 관리자는 'Efficient mode' 설정, 모델별 권한 부여, 조직/그룹/개인별 사용량 한도 설정 등을 통해 비용을 효과적으로 관리할 수 있습니다.
*   **통합 경험 즉시 활용 가능**: 통합된 Claude 경험은 오늘부터 Claude Enterprise 플랜에 대해 일반에 공개됩니다. 관리자는 조직 설정에서 이를 관리할 수 있으며, 기존 Claude Enterprise 고객에게는 이메일 안내가 발송됩니다.
