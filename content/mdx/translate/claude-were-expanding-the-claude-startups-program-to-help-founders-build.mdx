Anthropic은 Claude를 기반으로 회사를 구축하는 창업가를 지원하기 위해 Claude 스타트업 프로그램을 확장합니다.

-   **Claude Team 1년 무료 제공:** 신규 팀을 위한 최대 5개의 Premium 좌석을 제공합니다.
-   **$1,000 API 크레딧 제공:** 즉시 API 연동 및 초기 평가를 시작할 수 있도록 지원합니다.
-   **AI 네이티브 기업 운영 도구 할인:** 영업, 디자인, 데이터 엔지니어링 등 스타트업 운영에 필요한 도구들에 대해 최대 $45,000 상당의 할인 및 크레딧을 제공합니다.
-   **Anthropic Applied AI 팀과의 오피스 아워:** 기술적인 문제 해결 및 모델 개발 방향에 대한 인사이트를 얻을 수 있습니다.
-   **Claude Marketplace 등록 지원:** Claude 사용자에게 제품을 노출하고, 커뮤니티 이벤트 및 뉴스레터 접근 권한을 제공합니다.

지난 5년 이내에 설립되었거나 2년 이내에 투자를 유치한 스타트업은 참여 자격이 있습니다. 자세한 내용은 원문에서 확인하세요.
