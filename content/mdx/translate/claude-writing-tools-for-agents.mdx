> 원문: [Writing effective tools for agents — with agents](https://www.anthropic.com/research/writing-tools-for-agents) — Anthropic Engineering
> 이 글은 원문의 핵심 내용을 요약한 것입니다. 저작권은 원문 저자에게 있으며, 자세한 내용은 원문에서 확인하세요.

LLM 에이전트가 실제 작업을 해결하도록 돕는 강력한 도구를 만들기 위해서는 새로운 접근 방식이 필요합니다. 본 글은 에이전트와 협력하여 도구를 개발하고 성능을 최적화하는 방법을 제시합니다.

-   **프로토타이핑 및 로컬 테스트:** 초기 도구 프로토타입을 빠르게 구축하고 로컬에서 테스트하여 에이전트의 사용성을 확인합니다. Claude Code와 같은 도구를 활용하여 라이브러리 및 API 문서를 제공하면 효과적인 개발이 가능합니다.
-   **종합적인 평가 실행:** 실제 사용 사례를 기반으로 다양한 평가 작업을 생성하고, 에이전트를 통해 도구 성능을 체계적으로 측정합니다.
-   **에이전트와의 협업을 통한 최적화:** 평가 결과를 분석하고, Claude Code와 같은 에이전트의 도움을 받아 도구의 구현 및 설명을 반복적으로 개선하여 성능을 향상시킵니다.

또한, 효과적인 도구 작성을 위한 핵심 원칙으로 다음을 강조합니다.

-   **적합한 도구 선택:** 에이전트의 제한된 컨텍스트를 고려하여 특정 고영향 워크플로우에 집중하는 전략적인 도구를 구축합니다.
-   **명확한 네임스페이싱:** 기능별로 도구를 그룹화하여 에이전트가 올바른 도구를 선택하도록 돕습니다.
-   **의미 있는 컨텍스트 반환:** 에이전트의 후속 작업을 지원하는 고품질의 관련성 높은 정보만을 반환합니다.
-   **토큰 효율성 최적화:** 페이징, 필터링, 트렁케이션 등을 활용하여 도구 응답의 컨텍스트 양을 최적화합니다.
-   **도구 설명 프롬프트 엔지니어링:** 명확하고 구체적인 도구 설명과 스펙을 작성하여 에이전트의 효과적인 도구 사용을 유도합니다.
