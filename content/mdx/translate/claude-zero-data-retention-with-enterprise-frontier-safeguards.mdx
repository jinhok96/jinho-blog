*   Anthropic이 Enterprise Frontier Safeguards(EFS)를 베타 출시하여, 제로 데이터 보존(ZDR)과 호환되면서도 정교한 오용을 탐지하는 자동화된 안전 모니터링 기능을 제공합니다.
*   EFS는 고객이 직접 관리하는 인프라에 저장된 데이터를 분석하여, 여러 요청에 걸쳐 발생하는 복잡한 공격 패턴을 식별하고 'Safety Case'를 생성합니다.
*   EFS는 고객의 입력/출력 데이터를 Anthropic이나 클라우드 제공업체가 보관하지 않으며, 모델 학습에도 사용되지 않아 데이터 보안 및 개인 정보 보호를 강화합니다.
*   EFS는 Claude Platform, Claude Platform on AWS, Amazon Bedrock, Claude on Google Cloud 등 다양한 환경에서 사용할 수 있으며, Amazon S3 또는 Google Cloud Storage를 통해 고객의 자체 스토리지에 데이터를 저장합니다.
