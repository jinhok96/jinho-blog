Next.js의 2026년 8월 보안 릴리스가 v16.3.3 (Active LTS) 및 v15.5.24 (Maintenance LTS) 버전으로 업데이트되었습니다. 이번 업데이트는 두 가지 치명적인 보안 취약점을 해결합니다.

- AVIF 이미지 최적화 시 인증되지 않은 원격 코드 실행 취약점이 발견되었습니다. 이는 `sharp` 라이브러리가 사용하는 libheif의 취약점으로, 패치된 버전에서는 AVIF 최적화가 비활성화됩니다.
- Windows 환경에서 Pages Router와 App Router를 함께 사용하고 Cache Components를 사용하지 않는 경우, 인증되지 않은 원격 코드 실행 취약점이 발생할 수 있습니다. Linux 및 macOS는 이 문제의 영향을 받지 않습니다.
- Vercel의 오픈 소스 버그 바운티 프로그램을 통해 Next.js 보안에 기여할 수 있습니다.
