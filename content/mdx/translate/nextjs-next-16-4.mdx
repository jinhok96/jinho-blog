Next.js 16.4는 새로운 프로그래밍 모델인 Cache Components를 모든 Next.js 앱의 기본값으로 추천합니다. 이 모델은 초기 로딩 속도 향상, 서버 렌더링 앱의 즉각적인 클라이언트 네비게이션, 그리고 캐싱을 옵트인(opt-in) 방식으로 선언적이고 조합 가능하게 만드는 데 중점을 둡니다.

주요 변경 사항은 다음과 같습니다.

*   **Cache Components 기본 제공**: 모든 신규 앱에 Cache Components가 기본 활성화되며, 기존 앱도 도구를 통해 전환을 지원합니다.
*   **`ensureStatic` API**: 동적 컴포넌트가 의도치 않게 포함되는 것을 방지하여 빌드 시점에 페이지를 정적으로 유지하도록 보장합니다.
*   **`navigation()` 및 `prefetch()` API**: prefetch 중에 특정 컴포넌트의 로딩을 지연시켜, 사용자가 실제로 네비게이션할 때 로드되도록 제어할 수 있습니다.
*   **Agent 업그레이드 및 피드백 기능**: `next upgrade --agent` 명령과 `experimental.agentUpgrade` 설정을 통해 앱 업그레이드를 자동화하고, Agent 피드백 워크플로우를 통해 Next.js 팀에게 개선 사항을 제안할 수 있습니다.
*   **성능 최적화**: Turbopack의 디스크 캐시 크기 감소, Lazy Server HMR, Turbopack 공유 런타임, 더 작은 프로덕션 번들, 그리고 React 19.3 통합 등 다양한 개선이 이루어졌습니다.
