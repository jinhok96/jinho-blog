Next.js 16.3.3 및 15.5.24 버전이 8월 25일에 예정보다 앞당겨 출시됩니다.

- 이번 릴리스는 기존에 알려진 1개의 취약점 외에 새로 발견된 1개의 치명적인 취약점, 총 2개를 해결합니다.
- 두 취약점을 하나의 릴리스로 통합하여 사용자가 한 번만 업그레이드하도록 편의성을 높였습니다.
- 패치된 버전은 전체 보안 권고 사항과 함께 오늘 중으로 공개될 예정입니다.
- Vercel의 Open Source Bug Bounty 프로그램을 통해 Next.js 보안 강화에 기여하고 있으며, 관련 문의는 security@vercel.com으로 받습니다.
