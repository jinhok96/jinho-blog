Next.js v16.4.5 (Active LTS) 및 v15.5.29 (Maintenance LTS)에 대한 보안 업데이트가 배포되었습니다. 이번 업데이트는 Next.js 애플리케이션의 보안을 유지하기 위해 중요하며, Next.js 종속성을 최신 버전으로 패치할 것을 권장합니다.

주요 보안 문제 및 변경 사항은 다음과 같습니다:

- `unstable_cache`와 `use cache` 조합 시 발생하는 `Cross-tenant cache disclosure` (High Severity): Cache Components가 활성화된 애플리케이션에서 동일한 public `use cache` 함수가 직접 호출되거나 `unstable_cache` 내부에서 호출될 때, 다른 테넌트의 캐시된 콘텐츠가 노출될 수 있습니다.
- 중첩된 `use cache` 함수에서 발생하는 `Cross-root-parameter disclosure` (Medium Severity): Cache Components 및 중첩된 public `use cache` 함수를 사용하는 경우, 한 root-parameter 값에 대해 생성된 콘텐츠가 다른 root-parameter 값에 대한 요청에 제공될 수 있습니다.
- 이진 `use cache` 인자를 통한 `Cross-user cache disclosure and poisoning` (Medium Severity): 구별되는 이진 인자가 동일한 캐시 ID를 생성할 수 있어, 다른 사용자의 캐시된 결과가 노출되거나 자신의 결과가 다른 사용자에게 제공될 수 있습니다.
- 자체 호스팅 애플리케이션에서의 `Shared shell cache poisoning` (Medium Severity): `next start`를 실행하는 자체 호스팅 애플리케이션에서, 인증되지 않은 요청으로 인해 다른 URL에서 사용되는 페이지 쉘이 오염될 수 있습니다.
- `Stale compressed response framing`을 통한 `Cross-client response injection and disclosure` (Medium Severity): 특정 HTTP/1.1 리버스 프록시 환경에서, 공격자가 다른 클라이언트의 응답을 주입하거나 자신의 응답을 받을 수 있습니다.
- App Router Edge Route Handlers 및 Pages Router Edge API 라우트에서 `NextResponse.cookies.set()` 사용 시 `x-middleware-set-cookie` 헤더를 통해 쿠키가 노출될 수 있습니다.
- Image Optimization에서 `SVG rejection bypass` (Medium Severity): 악의적인 SVG 이미지가 AVIF로 잘못 분류되어, 애플리케이션이 사용하지 않도록 구성한 SVG 파서에 도달할 수 있습니다.
