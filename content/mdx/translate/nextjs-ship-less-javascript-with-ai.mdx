Next.js 16.4에서는 AI 에이전트가 JavaScript 번들 분석 및 최적화를 자동화할 수 있는 새로운 기능을 제공합니다. Turbopack 번들 분석기를 활용하여, AI 에이전트는 예상치 못한 임포트 관계를 파악하고, React Server Components로 로직 이동, 중복 의존성 제거, 미사용 코드 트렁크 셰이킹 적용 등의 최적화를 수행합니다. Vercel에서는 이 기능을 통해 이미 압축된 JavaScript를 약 2MB 줄이는 성과를 거두었습니다.

*   **AI 에이전트 기반 자동 번들 최적화:** `next-bundle-optimizer` 스킬을 사용하여 AI 에이전트가 JavaScript 번들을 자동으로 분석하고 최적화합니다.
*   **자동 최적화 기능:** React Server Components로 로직 이동, 중복 대형 의존성 제거, 트렁크 셰이킹 미적용 코드 수정 등을 수행합니다.
*   **개선된 번들 분석기:** 라우트별 번들 크기 요약, 번들 변경 사항 비교, 크리티컬 렌더링 경로에 대한 집중 분석 기능을 제공합니다.
