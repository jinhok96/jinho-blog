OpenAI API를 사용할 때 사용자가 기다리는 시간을 최소화하기 위한 최적화 전략을 안내합니다. API 요청이 응답을 시작하기까지 걸리는 시간인 Time to first token(TTFT)과 사용자가 최종 결과를 받을 때까지 기다리는 End-to-end latency를 측정하고 분석해야 합니다.

핵심 최적화 원칙은 다음과 같습니다.

- **토큰 처리 속도 향상:** 모델의 응답 생성 및 처리 속도를 개선합니다.
- **생성 토큰 수 감소:** 불필요하게 많은 토큰을 생성하지 않도록 합니다.
- **입력 토큰 수 최소화:** API 요청에 사용되는 입력 토큰의 양을 줄입니다.
- **요청 횟수 절감:** 가능한 한 API 요청 횟수를 줄여 통신 오버헤드를 감소시킵니다.
- **병렬 처리 활용:** 독립적인 작업을 동시에 처리하여 전체 소요 시간을 단축합니다.
- **사용자 대기 시간 단축:** 사용자가 실제로 체감하는 대기 시간을 줄이는 데 집중합니다.
- **LLM 의존성 완화:** 모든 경우에 LLM을 사용하기보다는, 가능한 경우 다른 방식을 활용합니다.

모델 선택 시 작업의 복잡성을 고려하고, 품질 목표를 충족하는 가장 빠른 설정을 유지하는 것이 중요합니다. 지원되는 경우 Fast mode 또는 Ultrafast mode를 활용하여 응답 시간을 단축할 수 있습니다.

긴 응답의 경우, 첫 번째 텍스트 이벤트부터 마지막 텍스트 이벤트까지의 시간 동안 초당 출력 토큰 수를 측정하여 가시적인 출력 속도를 평가합니다.

Chat Completions API에서는 `Predicted Outputs` 기능을 활용하여 이미 답변의 대부분을 알고 있을 때 생성 시간을 줄일 수 있습니다.

응답이 빠르게 시작되지만 완료하는 데 시간이 너무 오래 걸리는 경우, 모델이 생성하는 내용을 면밀히 검토해야 합니다. 사용자가 필요로 하는 정보의 양을 명확히 지정하고, `text.verbosity` 설정을 조정하여 응답 길이를 제어할 수 있습니다. 또한, `reasoning.effort`를 낮추어 불필요한 추론을 줄이고, `Structured Outputs`를 사용하여 필요한 필드만 요청하는 것이 효율적입니다.

긴 프롬프트는 첫 번째 토큰 지연 시간을 늘릴 수 있으므로, 검색 결과의 관련성을 필터링하고 불필요한 마크업을 제거한 후 필요한 맥락만 보내야 합니다. 반복적인 입력의 경우, 안정적인 지침, 예시, 도구 정의를 먼저 배치하고, 프롬프트 캐싱 기능을 활용하여 동일한 접두사 일치 시 재사용합니다.

순차적인 모델 또는 도구 호출은 추가적인 대기 시간을 유발하므로, 하나의 요청으로 필요한 모든 정보를 처리할 수 있도록 단계를 결합하는 것이 좋습니다. 여러 번의 짧고 순차적인 도구 호출이 필요한 경우, WebSocket mode를 사용하여 연결을 재사용하고 오버헤드를 줄일 수 있습니다.

독립적인 작업은 동시에 실행하여 전체 시간을 단축합니다. 예를 들어, 주문 ID를 얻은 후 반품 정책을 가져오는 동안 배송 상태를 조회할 수 있습니다. 지원되는 모델에서는 비동기 도구 호출을 통해 모델이 애플리케이션이 도구를 실행하는 동안 독립적인 작업을 계속하도록 할 수 있습니다.

불확실하지만 가능성이 있는 분기 작업의 경우, 읽기 전용 조회를 미리 시작하고 불필요한 경우 폐기하는 것을 고려합니다. 대화형 텍스트의 경우, `stream: true` 옵션을 사용하여 응답을 스트리밍하고 텍스트가 도착하는 대로 표시하여 사용자가 생성 완료 전에 읽기 시작할 수 있도록 합니다.

응답을 표시하기 전에 검사하거나 조정해야 하는 경우, 해당 작업을 수행할 충분한 텍스트를 버퍼링해야 합니다. 장기 작업의 경우, 조회 중에 "주문 조회 중"과 같이 실제 진행 상황을 표시합니다. 사용자가 나중에 결과를 다시 확인할 수 있는 경우, Background mode를 사용하여 작업을 비동기적으로 제출하고 결과를 검색할 수 있습니다.

이미 답을 알고 있는 경우에는 애플리케이션 코드를 사용합니다. 예를 들어, 주문 API에서 주문 상태를 렌더링하거나 템플릿을 사용하여 환불 성공을 확인하거나 검색 결과를 직접 표시하는 방식으로 모델 호출을 제거할 수 있습니다.
