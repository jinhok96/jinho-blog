> 원문: [Tailwind Labs is joining Shopify](https://tailwindcss.com/blog/tailwind-is-joining-shopify) — Tailwind CSS Blog
> 이 글은 원문의 핵심 내용을 요약한 것입니다. 저작권은 원문 저자에게 있으며, 자세한 내용은 원문에서 확인하세요.

*   Tailwind Labs가 Shopify에 합류하여 Tailwind CSS 프레임워크의 안정적인 장기적 보금자리를 확보합니다.
*   Shopify는 Tailwind CSS를 자체 플랫폼에 광범위하게 사용하고 있으며, 이를 통해 Tailwind CSS는 실제 제품 환경에서의 도전 과제를 해결하며 발전할 것입니다.
*   Tailwind CSS와 관련된 모든 오픈소스 프로젝트는 MIT 라이선스를 유지하며, 기존 팀이 Shopify의 지원하에 계속해서 개발 및 유지보수를 담당합니다.
*   상업적 측면에서는 Tailwind Plus, ui.sh 등 기존 고객에게는 모든 접근 권한이 유지되지만, 새로운 고객 등록은 종료되어 Tailwind CSS 개발에 집중합니다.
