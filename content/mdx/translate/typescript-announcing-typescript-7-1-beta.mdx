TypeScript 7.1 베타 버전이 출시되었습니다! 이번 릴리스에서는 import attributes 지원, Source Phase Imports, es2026 타겟 및 라이브러리 지원, API 개선, 그리고 상당한 성능 최적화가 이루어졌습니다.

주요 변경 사항은 다음과 같습니다.

- **Ambient Modules에 Import Attributes 지원**: import 문에 메타데이터를 추가하여 런타임 및 번들러가 모듈 내용을 해석하는 방식을 지시할 수 있습니다.
- **Source Phase Imports**: 모듈이 파싱되고 분석되었지만 아직 로드되지 않은 상태의 모듈을 나타내는 `AbstractModuleSource` 객체를 가져옵니다. WebAssembly 모듈을 인스턴스화하거나 JavaScript 모듈을 동적으로 가져오는 데 활용될 수 있습니다.
- **`--target es2026` 지원**: ECMAScript 2026의 안정화된 기능을 타겟으로 삼을 수 있으며, `Math.sumPrecise()`, `Iterator.concat()`, `JSON.rawJSON()` 등 새로운 라이브러리 메서드가 추가되었습니다.
- **새로운 TypeScript 7.1 API**: TypeScript의 구문 및 의미 분석을 활용하여 강력한 도구와 유틸리티를 구축할 수 있는 새로운 API가 여러 엔트리 포인트로 제공됩니다. `typescript/sync`, `typescript/async`, `typescript/fs`, `typescript/ast` 등이 포함됩니다.
- **다양한 최적화**: 메모리 압력을 줄이고 빌드 속도를 높이기 위한 여러 최적화가 적용되어 전반적인 성능이 향상되었습니다.
