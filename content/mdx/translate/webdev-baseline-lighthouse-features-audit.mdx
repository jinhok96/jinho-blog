# Lighthouse에 Baseline Features 감사 기능이 추가되었습니다

![Jeremy Wagner](https://web.dev/images/authors/jlwagner-v7.jpg)

## Baseline Features 감사 기능이 Lighthouse에 추가되었습니다

[Baseline Features 진단 감사](https://developer.chrome.com/docs/lighthouse/best-practices/baseline-features) 기능이 [Lighthouse](https://developer.chrome.com/docs/lighthouse)의 모범 사례 감사 카테고리에 포함되었습니다. 이 감사는 페이지에서 감지된 웹 플랫폼 기능의 [Baseline](https://web.dev/baseline) 상태를 보고하여, Lighthouse 보고서 내에서 직접 브라우저 상호 운용성 정보를 제공합니다.

이 감사는 [`web-features` 패키지](https://www.npmjs.com/package/web-features)를 기반으로 하며, 타사 스크립트와 활성 브라우저 확장 프로그램의 기능을 포함하여 페이지에서 사용되는 웹 플랫폼 기능을 식별합니다. 감지된 각 기능의 Baseline 상태—널리 사용 가능, 새로 사용 가능, 제한적 사용 가능—를 식별하고, 해당 기능이 페이지 소스 코드의 어느 위치에 나타나는지 보여주며 [webstatus.dev](https://webstatus.dev/)의 웹 기능 항목에 대한 링크를 제공합니다.

Baseline Features 감사는 Lighthouse와 Chrome DevTools의 현재 버전에서 사용할 수 있습니다. Lighthouse에서 모든 페이지에 대해 이 감사를 실행하여 기능 사용을 검사하고 브라우저 호환성 데이터를 확인할 수 있습니다.
